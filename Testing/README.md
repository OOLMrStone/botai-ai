# Локальное тестирование BotAI

Передай агенту [App/prompt.md](App/prompt.md): там полный запуск из одного клона,
тестовые аккаунты, три кабинета и проверка полного пути без платной модели.

- `App/frontend/` — интерфейсы ученика, эксперта и проверки ИИ.
- `App/backend/` — API и локальная инфраструктура.
- `evals/14` … `evals/20` — канонические eval-наборы; `tasks/N/evals` — совместимые ссылки.

Пример с зачёркнутым π: [ФИПИ 13.3.2](evals/14/fipi/13.3.2/solution.png),
проектный номер 14. `expected.json` и исторические экспертные оценки — только
для сравнения результатов; не передавай их модели. Приложение использует фото
условия/официального ответа отдельно от фото решения ученика.
