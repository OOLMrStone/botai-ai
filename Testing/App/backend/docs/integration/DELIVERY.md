# BotAI: готовые частные стенды

Большой Storefront и учебное приложение объединены в основном frontend `develop`. На Mac и отдельном серверном стенде запущены frontend, backend, PostgreSQL, private S3, AI, Mailpit и Adminer — **7+7 сервисов**. Существующий публичный production не переключался.

| Открыть | Локально | Сервер через SSH-туннель |
|---|---|---|
| Сайт | [BotAI](http://127.0.0.1:13000) | [BotAI stage](http://localhost:23000) |
| База, Adminer | [PostgreSQL](http://127.0.0.1:18090/?pgsql=postgres&username=botai_operator&db=botai) | [PostgreSQL stage](http://localhost:28090/?pgsql=postgres&username=botai_operator&db=botai) |
| Тестовая почта | [Mailpit](http://127.0.0.1:18025) | [Mailpit stage](http://localhost:28025) |

`test@test.test` готов на обоих сайтах: USER, тестовый Pro, почта подтверждена. Пароль задан пользователем и хранится только в private credentials. **Все прежние тестовые аккаунты сохранены.** Логины и пароль оператора: локально `runtime/credentials.json`, серверные — `runtime/evidence/stage-credentials.json` (0600, вне Git). Ссылки Adminer уже выбирают PostgreSQL/postgres/botai/botai_operator; остаётся ввести пароль оператора. Локальный сайт открывать через127, серверный черезlocalhost — это разделяет cookies.

## Что работает

- Каталог 20 номеров/140 тем; подборки с выбранным количеством задач, пробники по 20 заданий, избранное, профиль, аватар, регистрация и почта. HOME показывает все незавершённые попытки; ответы, рисунки, фото, результаты и позиция сохраняются после выхода/перезагрузки.
- Фото и аватары находятся в частном S3; PostgreSQL хранит пользователей, попытки, метаданные, очередь и историю. Backend проверяет владельца/роль и передаёт AI доверенные данные задания и фото.
- Продуктовая админка `/admin/submissions` для ADMIN показывает проверки, фильтры, события, фото и точный AI JSON. Управление пользователями/ролями/банком задач здесь не реализовано. Adminer — отдельный просмотр безопасных представлений только для чтения.
