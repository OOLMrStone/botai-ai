# Testing App

[Полная инструкция для человека или агента без контекста](prompt.md).

Запуск из корня репозитория: `python3 Testing/App/run.py up`.
Кабинеты ученика, эксперта и проверок ИИ используют настоящий локальный backend;
первый запуск работает с mock AI. Для реального OCR нужен собственный API-ключ.

`frontend/` и `backend/` — самостоятельные исходники тестового приложения в этом
репозитории, а не ссылки на папки на машине основателя. AI собирается из корневых
`app/` и `tasks/*/prompts/`. Данные и пароли создаются только в игнорируемом runtime.
