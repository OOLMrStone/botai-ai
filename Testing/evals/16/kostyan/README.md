# kostyan_evals

Источник — [публичная папка Кастяна на Яндекс Диске](https://disk.360.yandex.ru/d/mN-r2pZegKg2eA).

По уточнению пользователя оставлены только материалы задания 15 и **один тест «прислали не то» — M2**, использующий фото14.jpg с чужим решением. Прочие фотографии задания13, второй тест подмены M4, мусорные картинки и смешанные исходные XLSX/DOCX/TXT удалены из локального набора. Нужные строки таблицы и тексты решений предварительно извлечены без изменения содержания.

## Состав

15 сценариев:14 математических и1 негативный. Для Б и Д проверяются по3 варианта фото, поэтому всего19 запусков:18 математических и1 ожидаемый отказ. Варианты одной работы не являются независимыми задачами. Файл13.jpg относится к заданию ЕГЭ15; имя файла не равно номеру задания.

Оценки репетитора взяты из E/F листа «Тестовый набор» исходной таблицы «Тесты бота-проверяющего.xlsx»; для всех выбранных работ они совпадают. Сохранённая выборка с исходными адресами ячеек находится в source-rows.json. Столбцы результатов старого бота эталоном не являются. Исходная смешанная таблица доступна по ссылке на источник, но локально не хранится.

Для M2 в старом наборе ожидался0. Современный контракт требует отказа без оценки; исходный0 сохранён как исторический, правильность отказа считается отдельно от совпадений математических баллов.

## Структура

- raw/ —16 исходных фотографий выбранных работ, включая единственное чужое фото14.jpg; байты сохранены без изменений.
- source-index.json —источник и SHA256 сохранённых оригиналов.
- source-rows.json, mapping.md —выбранные строки таблицы и соответствия сценариев/фото.
- image-inventory.json —визуальная проверка сохранённых фотографий.
- assets/crops/ —разделение соседних задач на16.2 и19.2; координаты и хеши в crop-log.json.
- problems/<id>/ —11 условий с правильными ответами и короткими эталонными решениями, в JSON/тексте/PNG.
- cases/<id>/ —изображения решения, expected.json и provenance.json; для текстовых сценариев также student-text.txt.
- manifest.json —19 подготовленных входов.

Условия восстановлены из источников. Правильные ответы проверены независимо алгеброй. Эталонные решения написаны агентом и явно отделены по происхождению от оценок репетитора. Текстовые решения учеников перенесены на изображения дословно, включая ошибки. Рукопись не перерисована; на двух общих страницах только разделены соседние задачи.

Модель получает одно изображение условия/ответа/эталонного решения и1–2 изображения работы. Ожидаемые баллы, описания дефектов, таблица оценок и старые логи модели не передаются. В отличие от Base ИВЛС, на картинке задачи здесь есть и короткий полный эталон; проценты двух разных наборов не следует трактовать как контролируемый эксперимент.
