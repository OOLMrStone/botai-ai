Преобразуем неравенство:

(log₂(32x) − 1)/(log₂²x − log₂x⁵) ≥ −1 ⇔ (5 + log₂x − 1)/(log₂²x − 5log₂x) ≥ −1.

Пусть t = log₂x, тогда

(4 + t)/(t² − 5t) ≥ −1 ⇔ (t² − 4t + 4)/(t² − 5t) ≥ 0 ⇔ (t − 2)²/(t(t − 5)) ≥ 0 ⇔

[ t < 0
[ t = 2
[ t > 5

(метод интервалов на оси t: точки 0 и 5 выколоты, точка 2 закрашена; знаки слева направо: +, −, −, +; заштрихованы промежутки t < 0 и t > 5)

Вернёмся к исходной переменной:

[ log₂x < 0            [ 0 < x < 1
[ log₂x = 2      ⇔     [ x = 4
[ log₂x > 5            [ x > 32

Ответ: (0; 1) ∪ {4} ∪ (32; +∞).
