# Оставшаяся работа

Текущий сервис уже принимает фото, выполняет ограниченный диалог с инструментами и возвращает один проверенный JSON. Сохранённые прогоны и ограничения — в [задании 16](../tasks/16/README.md).

1. Проверить гипотезы по распознаванию скобок, значимым утверждениям на рисунках и первопричинам ошибок; перед изменением промпта зафиксировать сравнимую базу. Платные прогоны только по прямому запросу.
2. Согласовать спорное применение критерия на наборе Кастян и место советов без ошибок. Не подгонять эталон под ответ модели.
3. Добавлять следующие задания отдельными пакетами и предметными evals. Папки 14–20 сами по себе не дают поддержку этих номеров.
4. Интегрировать основное приложение: реальные ID пользователей/фотографий, банк задач и историю проверок. Тестовую cookie не считать производственной идентификацией.
5. По потребности добавить экран приватных репортов, метрики, лимиты по пользователю и учёт затрат. Текущие ограничения и хранение описаны в сервисном контракте.

Исследовательская история и альтернативные предложения сохранены в архиве; это не обязательства по реализации.
