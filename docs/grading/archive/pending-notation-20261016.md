# Сохранённый незавершённый вариант проверки TeX

При очистке веток 21 октября найдены два незакоммиченных файла в рабочей
копии structured-json-validation-fixes. Соседний patch сохраняет их отличия
от объединённого main. Он не подключён к приложению: этот вариант требует
TeX для любой математической записи и противоречит более поздним тестам
основной реализации, которые допускают простую текстовую математику.

Материал перенесён в develop для отдельного решения, без отката проверенного
контракта main. Исходная рабочая копия также сохранена.
