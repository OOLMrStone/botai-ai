# Сверка трёх рабочих копий — 29.09.2026

Перед уборкой сохранены независимые снимки `main`, `dfda` и `ec15`. Для действующего сервиса взята реализованная редакция `ec15`; более ранние договорённости проверены по двум другим снимкам. Это запись о сохранности, не новый контракт.

## Что различалось

- В `main` начальный промпт ещё не читал Statement/Solution перед OCR; запрет выполнять команды ученика уже действовал. Поздняя редакция сохраняет этот запрет и добавляет подготовку условия и эталона. Уникального отменённого требования к обычной проверке здесь нет.
- Старый JSON не имел корневых `is_graded`/`rejection_reason`. Для другой задачи `grading.is_target_task=false` требовал `score=0`, `criterion=null`, `analysis.checks=null`, `analysis.student_answer=null`, пустые `errors`/`strengths` и объяснение «Решено не то неравенство»; OCR сохранялся, summary мог объяснять несовпадение. Это **отменённый контракт**, теперь применяется отказ без оценки.
- Для объективной нечитаемости ранее предлагался `finish_ungradable` без JSON оценки. Нельзя было использовать его из-за сложности математики, ошибки ученика или сомнения проверяющего; серверный допуск не доказывал нечитаемость. Предложение сохранено в [старой спецификации](server-file-reading-spec.md), действующий инструмент — `set_rejection` с валидируемым JSON.
- В `dfda` новый формат отказа уже описан, но валидатор и приложение ещё отмечались как не обновлённые. В `ec15` они реализованы. Различия README, AGENTS и service-idea об этом — последовательные статусы, не потерянные идеи.
- Первоначальный автономный валидатор содержал полную реализацию в документной папке: строгий полный JSON без обёртки и повторных ключей, E-коды из таблиц, уникальность ID ошибок и допуск точного проверенного текста. Эти свойства сохранены в общем сервисном валидаторе; старый CLI заменён оболочкой. Старые проверки `is_target_task` отменены вместе с контрактом.
- Старый response-template отличался устаревшим `is_target_task`; это был шаблон с заполнителями, не оценённая работа. Пожелания к полям и советы без ошибок сохранены в [for-rating.md](for-rating.md) и предметной истории.

Все файлы документов из более ранних снимков имеют соответствия в `ec15`; уникальных файлов, отсутствующих там, не обнаружено. Дословные пользовательские цитаты и предметные исследования сохранены в [истории задания 16](../../../tasks/16/hypotheses/history.md). Отдельные полные дубликаты README/AGENTS/валидатора не добавлялись: они увеличили бы архив без новых требований.
