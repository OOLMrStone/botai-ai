# Каталог советов: неравенства

Используй после выбора оценки вместе с `advice.md`. Это поводы для полезного совета, не дополнительные критерии и не готовые замечания. Код ошибки помогает найти тему; совет разрешён только при подтверждённом факте. При верной ясной работе пустой список нормален.

| ID | Когда полезен | Действие и польза |
| --- | --- | --- |
| A01 | Непроверенный ложный «⇔»; особенно вычислительный случай S02 | Проверять равносильность, а вычисление показывать отдельным действием. Можно разделять этапы строками или `;`: это помогает не давать эксперту дополнительного основания прочитать вычислительный сбой как ложное утверждение равносильности. Ошибку всё равно исправить; при неверном методе сначала объяснить сам метод |
| A02 | Ошибочная или противоречивая ОДЗ; вычислительный сбой S01; перепутаны «и»/«или» | Проверить условия существования исходных объектов и их пересечение, отдельно пересчитать ограничения и проверить их в исходных условиях. Сделать видимым действующее ограничение, явно исправить ошибочную строку. Так эксперт не примет старое ложное ограничение за часть доказательства. Не требовать повторения избыточных условий или отдельного заголовка |
| A03 | В ответ включена запрещённая точка либо перепутана допустимость со строгостью | Сначала проверить определённость исходного выражения на концах, затем допустимость равенства. Нули знаменателя отмечать выколотыми и сверять с итоговыми скобками |
| A04 | Решение остановлено в новой переменной или неверно учтён её диапазон | После решения для `t` вернуться к связи с `x`, решить её и записать множество для исходной переменной. Диапазон устанавливать из функции, не автоматически требовать `t>0` |
| A05 | Знаки интервалов чередуются без основания, потеряна кратность или изолированный нуль | Проверять знак каждого интервала и отдельно значение в допустимых нулях. Показывать достаточное основание: рационализацию, кратности либо пробные точки при установленном постоянстве знака |
| A06 | Установлен вычислительный сбой или ошибка переписывания | Проверять конкретное уязвимое действие: обратная операция, раскрытие скобок, пересчёт границы; при переписывании сравнить числа, скобки и интервалы ответа с последним верным выводом. Выбрать действие именно для найденной причины |
| A07 | Верная рационализация изложена словами так, что непонятно, заявлено равенство или совпадение знаков | Указать свойство, оправдывающее переход: например, положительность знаменателя на ОДЗ или совпадение знаков заменяемых множителей. Название метода необязательно. За одно отсутствие названия совет не нужен |
| A08 | Отвергнутая ошибочная запись осталась незачёркнутой | Явно зачеркнуть отвергнутую строку и оставить читаемый правильный ход. Зачёркнутое не проверяется, незачёркнутая замена проверяется; нельзя советовать убрать неудобный шаг без правильного решения |

Не выдавай A01 только за наличие верного «⇔», A02 — за краткую правильную ОДЗ, A07 — за отсутствие названия метода. Общая рекомендация не должна превращаться в новый повод снизить оценку.

Для S01–S03 решение об оценке не принято. Каталог не назначает этим случаям балл и не предсказывает его; окончательный отзыв для них пока не утверждён.
