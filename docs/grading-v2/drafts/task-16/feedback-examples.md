# Объяснения и советы — примеры для человека

Проверка отдельных [feedback.md](../feedback.md) и [advice.md](../advice.md). Это синтетические примеры, не цитаты экспертов и не вход проверяемой модели. Балл и факты уже установлены; советы не пересматривают их. Предметные условия выбора — в [advice-catalog.md](advice-catalog.md).

## 1. S02: вычисление с ложным «⇔»

Вход: `2x≥6 ⇔ x≥2`. **Оценка: `<решение не принято>`.** Ранее приведённый окончательный отзыв на 0 снят. Полезная будущая тема совета — проверять равносильность и отдельно показывать вычисление; это не назначает балл.

## 2. Один балл: вычисление

Вход: `2x≥6`; «делим на 2: `x≥6/2=2`»; ответ `x≥2`. Единственная ошибка вычислительная, ложного «⇔» нет.

**Объяснение:**

> 1 из 2. Деление на положительное число выбрано верно, но `6/2=3`, а не 2. Все шаги способа решения сохранены, ответ изменился из-за одного вычисления.

**Совет A06:**

> Перед ответом пересчитай полученную границу и проверь её в исходном неравенстве. Здесь подстановка `x=2` даёт `4≥6` и сразу обнаруживает ошибку.

Не добавлять совет о ложном «⇔»: этого знака в работе нет.

## 3. S03: верное решение, неверно переписанный ответ

Вход: `(x−1)/(x−2)≥0` верно решено; в выводе `(-∞;1]∪(2;+∞)`, в «Ответ» — `(-∞;−1]∪(2;+∞)`. **Оценка: `<решение не принято>`.** Окончательный отзыв на 1 снят. Возможная тема будущего совета — сверить числа, скобки и интервалы при переносе ответа; совет не назначает балл.

## 4. Один балл: допустимая граничная точка

Вход: для `x−3>0` всё остальное верно, в ответ включено 3; ложного «⇔» нет.

**Объяснение:**

> 1 из 2. Точка 3 включена в ответ, хотя в ней получается `0>0`. Здесь единственная ошибка — включённая допустимая граница.

**Совет A03:**

> После проверки допустимости конца подставь его в неравенство и посмотри, разрешено ли равенство. Здесь знак строгий, поэтому ответ `x>3`.

## 5. Ноль: запрещённая точка

Вход: `(x−1)/(x−2)≥0`; знаки верны, ответ `(-∞;1]∪[2;+∞)`.

**Объяснение:**

> 0 из 2. Интервалы знаков найдены верно, но при включённом `x=2` знаменатель равен нулю. Именно запрещённое значение в ответе стало основанием для нуля; это не ошибка только в строгости на допустимой точке.

**Совет A03:**

> На оси сразу отмечай нули знаменателя выколотыми и сохраняй этот запрет в ответе. Нестрогий знак неравенства не разрешает деление на ноль: здесь второй промежуток `(2;+∞)`.

## 6. Ноль: не выполнен возврат

Вход: `2^x≥4`; «`t=2^x`, `t≥4`, ответ `t∈[4;+∞)`», балл 0.

**Объяснение:**

> 0 из 2. Неравенство для новой переменной получено, но задача требует ответа для `x`. Возврата нет, поэтому исходная задача ещё не решена.

**Совет A04:**

> После любой замены вернись к связи между переменными и реши её. Здесь `2^x≥2²` даёт `x≥2`, поскольку основание 2 больше 1; в ответе должна стоять исходная переменная.

Это требование выполнить отсутствующий математический шаг, а не переписать уже выполненное начисто.

## 7. Два балла: короткое ясное решение

Вход: вся математика верна, ограничения учтены поздним отбором, отдельного заголовка ОДЗ нет.

**Объяснение:**

> 2 из 2. Решение обосновано, ограничения учтены при окончательном отборе и ответ верен.

**Советы:** пустой список. Не требовать заголовок ОДЗ или повторение избыточного условия.

## 8. Два балла: рационализация без названия

Вход: верная и ясная рационализация, P01, балл 2.

**Объяснение:**

> 2 из 2. Преобразования и итоговый отбор выполнены верно.

**Советы:** пустой список. Отсутствие названия не создаёт полезного повода для совета. Если именно неоднозначная словесная запись затрудняет чтение, это другой случай для A07: предложить конкретное пояснение свойства, а не обязательное название метода.

## 9. S01: вычислительная ошибка в ОДЗ

Вход: верные `x+6>0, x+6≠1`, затем неверное вычисление `x≠1−6=−7`. **Оценка: `<решение не принято>`.** Окончательный отзыв на 0 снят; пересчёт и проверка исключений остаются возможными темами совета после экспертного решения.

## 10. Один балл: вычислительная ошибка при совпавшем ответе

Вход: `2x≥6`; `x≥6/2=2`; ответ `x≥3`. Одна вычислительная ошибка, остальные шаги верны; нет ОДЗ и ложного «⇔».

**Объяснение:**

> 1 из 2. Итоговый ответ верный, но в решении осталось неверное вычисление: `6/2=3`, а не 2. Совпадение ответа не отменяет эту ошибку.

**Совет A06:**

> Пересчитай действие в решении и сверь его с ответом. Если исправляешь запись, зачеркни ошибочную и оставь правильную читаемой.

При нескольких независимых вычислительных ошибках даже совпавший ответ оставляет 0 по E06. Это установленное правило, не S03.

## Контрасты, защищающие смысл советов

| Наблюдаемое различие | Что должен сделать советник |
| --- | --- |
| `2x≥6 ⇔ x≥3` верно | Не отучать от правильно использованного «⇔» |
| `−2x≥6`, затем `x≥−3` | Исправить правило деления на отрицательное: `x≤−3`; пунктуация не решает проблему |
| Корректное следствие добавило кандидатов | Предложить полный отбор по исходным условиям; не объявлять «⇒» универсально безопасной заменой |
| Переход потерял решения | Потребовать восстановления пропущенной ветви; отбор оставшихся кандидатов потери не исправляет |
| Верная краткая ОДЗ / явно ложная ОДЗ | В первом случае совет может отсутствовать; во втором нужно исправить конкретное условие, не просто удалить заголовок |
| Неназванная верная рационализация / неверная замена слагаемых | В первом случае не нужен ритуальный совет; во втором исправляется метод |
| Явно исправленная ошибка / две действующие противоречивые записи | Не подавать исправленную ошибку как действующую; во втором случае полезно явно оформить исправление |
| S01–S03 | `<решение не принято>`; окончательные отзывы пока не утверждены |

## Проверка качества

Объяснение должно соответствовать баллу и фактам. Совет должен быть связан с конкретной записью, давать выполнимое действие и понятную пользу. Ошибки, обязательные ритуалы и обещания баллов не добавляются. Разногласие экспертов упоминается только там, где оно известно; повторять оговорку в каждом абзаце не нужно.
