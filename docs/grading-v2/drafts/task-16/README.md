# Пакет проверки неравенств

Черновик `task16-v3`, 24.09.2026. Папка проекта называется `task-16`; источник ФИПИ-2026 — задание 15. В действующий сервис пакет ещё не подключён; качество модели на нём пока не измерено.

## Вход и файлы модели

Один диалог: сервер передаёт короткий [start.md](start.md), условие, известный математический ответ и фото; модель читает остальные файлы через `read_file`. Названия в левом столбце — виртуальные имена инструмента, ссылки — реальные расположения.

| Имя для модели | Файл | Назначение |
| --- | --- | --- |
| `criteria.md` | [criteria.md](criteria.md) | Критерии |
| `rules.md` | [rules.md](rules.md) | Общие правила классификации |
| `pitfalls.md` | [pitfalls.md](pitfalls.md) | Тематические ошибки, допустимые записи, спорные ситуации |
| `analysis.md` | [analysis.md](analysis.md) | Проверка фото и отчёт фактов |
| `grading.md` | [grading.md](grading.md) | Выбор балла и формат результата |
| `feedback.md` | [feedback.md](../feedback.md) | Объяснение оценки |
| `advice.md` | [advice.md](../advice.md) | Отдельные советы ученику |
| `advice-catalog.md` | [advice-catalog.md](advice-catalog.md) | Предметные советы |

`analysis` и `grading` — части результата одного диалога, не обязательные отдельные модельные стадии. Чтение инструментом требует продолжений API-диалога. Один диалог не означает один API-запрос. Вариант разделения стадий можно исследовать позже на тех же предметных файлах.

Файлы и их версии закрепляются на весь запуск. Индивидуальные критерии передаются отдельно и имеют приоритет. Данные ученика отделяются границами `<<<РЕШЕНИЕ_УЧЕНИКА` / `>>>КОНЕЦ_РЕШЕНИЯ`; фотографии маркируются как работа ученика. Известный математический ответ разрешён, экспертный балл скрыт.
