# Экспертные случаи: решения и открытые вопросы

Только для человека, не для промпта. Ниже короткие работы для калибровки, часть основана на опубликованных разборах. Решения пользователя от 23.09.2026 отделены от найденных источников; это не новые вердикты ФИПИ. Дословные заметки — в [human-notes.md](../../human-notes.md), соответствие прежних ID — в [changes.md](changes.md).

## 1. Избыточное условие в объявленной ОДЗ

Задача: `log₂(x−1)+log₂(x+1)≥0`. Верный ответ `[√2;+∞)`.

Работа: «ОДЗ: `x−1>0`, значит `x>1`. `log₂(x²−1)≥0`, поэтому `x²≥2`. При `x>1` получаем `[√2;+∞)`».

**Решение пользователя: 2.** Условие `x+1>0` следует из `x>1`; его можно не повторять даже в объявленной ОДЗ. Для нуля за случайно правильную ОДЗ нужно конкретное неверное рассуждение, а не отсутствие избыточной строки.

**Почему вопрос:** прежний E03 давал 0; эксперт Бабаев допускает отдельный аналогичный пропуск вложенного условия, но минимальной пары оценённых работ с одним изменённым заголовком нет. Источники: ФИПИ с.87; [заметка 09.06.2026](https://t.me/egenaprogib/3323).

## 2. Ложная ОДЗ, которая далее не используется

Задача: `(x²+2x)/log₂(9·3^x)≤0`. Верный ответ `(-∞;−2)∪(−2;0]`.

Работа: «ОДЗ: `x≠−2, x<0`». Затем правильно установлено `log₂(9·3^x)=(x+2)log₂3`; при `x≠−2` дробь равна `x/log₂3`. Получено `x≤0`, исключено `−2`, записан ответ `(-∞;−2)∪(−2;0]`. Строка `x<0` не зачёркнута.

**Решение пользователя: 0 по E02.** Явно ложная ОДЗ не исправлена, хотя далее не используется. Если ложное условие явно исправлено и остальное решение верно, основание для E02 исчезает.

**Почему вопрос:** [реальная работа и комментарий](https://t.me/egenaprogib/3557) показывают расхождение между выставленными 2 и возможной строгой оценкой. ФИПИ с.101/110 обсуждает ошибочную ОДЗ, которая участвует в решении; это не идентичная ситуация.

## 3. Ложный «⇔» и полный поздний отбор

Задача: `log₂(x)≥1`. Верный ответ `[2;+∞)`.

Работа: «`x>0`. `log₂(x)≥1 ⇔ (log₂(x))²≥1`. Отсюда `log₂(x)≤−1` или `log₂(x)≥1`, то есть `0<x≤1/2` или `x≥2`. Проверка по исходному неравенству: в первой ветви `log₂(x)≤−1<1`, вся ветвь не подходит; во второй `log₂(x)≥1`, вся ветвь подходит. Ответ: `[2;+∞)`».

**Решение пользователя: 0 по E03; с правильным `⇒` и данным полным отбором — 2.** Поздний отбор не исправляет неисправленное ложное утверждение равносильности. Вычислительный случай `2x≥6 ⇔ x≥2` вновь открыт как S02: `<решение не принято>`. Не переносить ноль за неверный метод на него автоматически.

**Почему вопрос:** прежний E04 давал 0. Проверенной экспертной минимальной пары, изолирующей этот знак при полном отборе, не найдено. Отдельный близкий случай — незачёркнутая неверная попытка перед самостоятельным полным решением, см. C08 в validation-cases.md.

## 4. Вычисление в ОДЗ или неверное правило переноса

Задача: `log_(x+6)(2)≥0`. Верный ответ `x>−5`.

Работа: «`x+6>0`, `x+6≠1`, значит `x>−6, x≠−7`. При `x+6>1` логарифм положителен; при `0<x+6<1` отрицателен. Ответ: `x>−5`».

**S01: `<решение не принято>`.** Вычислительная ошибка — неверно полученное число в результате верного действия; случай подходит под определение. Оценка неверно вычисленной ОДЗ ожидает экспертного мнения. Интерпретация причины нуля в одной работе Бабаевым не является общим определением вычислительной ошибки.

**Почему вопрос:** [разбор реального случая 2024 года](https://t.me/egenaprogib/1576) описывает 0 за подобный переход; пояснение о причинах решения комиссии — интерпретация автора. Это не чистый образец ветви «неверный ответ из-за вычисления»: здесь ответ верен.

## 5. Две независимые вычислительные ошибки

Задача: `x²−5x+6≥0`. Работа: «`D=25−24=1`; `x₁=(5−1)/2=1`; `x₂=(5+1)/2=4`. Старший коэффициент положителен, выбираем внешние промежутки с концами. Ответ: `(-∞;1]∪[4;+∞)`».

**Решение пользователя: 0 по E06.** Две независимые ошибки; повторные последствия одного сбоя не считаются второй ошибкой.

**Почему вопрос:** [официальный отчёт Чувашии-2024, с.75–76](https://fs02.rchuv.ru/rchuv19/rchuv19/chrio/sitemap/2024/cb727f90-fcf4-4202-93c6-75018d2ad801/sbornik-po-sao-11-2024_21chuv.pdf#page=76) прямо задаёт 0 за две вычислительные ошибки. Пользователь подтвердил 0; текущий код E06. Общая таблица ФИПИ-2026 не содержит отдельной строки для числа вычислительных ошибок.

## 6. Верный вывод, неверно переписанный ответ

Задача: `(x−1)/(x−2)≥0`. ОДЗ и метод интервалов верны. В последней строке решения написано `(-∞;1]∪(2;+∞)`, а после слова «Ответ» — `(-∞;−1]∪(2;+∞)`.

**S03: `<решение не принято>`.** Это верное решение с неверно переписанным финальным ответом. Прежняя оценка 1 отменена. Если в ответ включено запрещённое значение, отдельное правило E01 на 0 сохраняется.

**Результат целевого исследования:** первичный пример именно с ошибкой в финальном ответе не найден. [Бабаев, 2352](https://t.me/egenaprogib/2352): 2 за работу с разовой опиской внутри решения, правильное число восстановлено, итог верен. Это не подтверждение оценки S03. [Пост 2942](https://t.me/egenaprogib/2942) с 1 за ошибку в последней строке относится к экономической задаче, поэтому здесь неприменим. Балл ожидает решения экспертов.

## 7. Очевидный возврат из замены не написан

Задача: `2^x≥4`. Вся работа: «`t=2^x`; `t≥4`. Ответ: `t∈[4;+∞)`».

**Решение пользователя: 0 по E09.** Ответ нужен для исходной переменной; возврат из замены обязателен. Переписывание исходного неравенства вместо его решения также не завершает задачу.

**Основание:** общие критерии требуют законченного решения; пользователь подтвердил трактовку для указанной простой замены. Независимый экспертный скан этой минимальной работы не найден.

## 8. Локальная ошибка при правильном итоговом ответе

Например, `2x≥6`; «делим на 2: `x≥6/2=2`»; затем ответ `x≥3`. Ошибочная строка не зачёркнута. Это отличается от S03, где верное решение заканчивается ошибочно переписанным ответом.

**Решение: 1 при одной вычислительной ошибке, 0 при нескольких независимых.** Остальной ход верен; случайное совпадение ответа не отменяет ошибок. Это не S03. Для вычислений в ОДЗ/с ложным «⇔» отдельно открыты S01/S02.

## 9. Краткий рациональный переход: вопросы после исследования

Для `(x−1)/(x−2)≥0` сравнить: готовое `(x−1)(x−2)≥0` при `x≠2` и сразу правильный ответ без оси; ось с точками и выбранными промежутками, но без подписанных знаков. Какие минимальные записи достаточны? Числовые метки этим вариантам пока не назначены.

Исследование показало допустимость готовой факторизации без деления многочлена и расстановки знаков без отдельного обоснования. Ни один источник не закрывает автоматически отсутствие самого анализа знаков. [Источники и границы](justification-research.md).
