# Анализ фотографии

## Проверка

| Шаг | Действие |
| --- | --- |
| Записи | Сохранить читаемые действующие записи с ID и областью фото. На оси различать знаки интервалов, знаки в точках, включённые точки и выбранные промежутки |
| Область определения | Проверить исходную ОДЗ и ограничения переходов |
| Преобразования | Проверить каждый существенный переход на действующих ограничениях |
| Полнота | Проверить ветви, интервалы, отбор и возврат из замены |
| Ответ | Сравнить множества. Ясно полученное итоговое множество считается ответом без отдельного слова «Ответ». Если отдельный ответ противоречит верному выводу, сохранить обе записи и отметить S03 |
| Обоснование | Для каждого пробела назвать недоказанный факт. Эталон не дописывает решение за ученика |
| Причина | Классифицировать недостаток по `rules.md`, связать последствия с первопричиной |
| Неясность | Вернуться к фото. Непрочитанный символ не считать математической ошибкой. При противоречии проверенного вывода эталону перепроверить оба |

## Отчёт анализа

| Поле | Содержание |
| --- | --- |
| `transcript` | ID, фото/область, буквальная запись, `active/uncertain`. Неоднозначное чтение — отдельные варианты |
| `checks` | ОДЗ; переходы; полнота/возврат; ответ. Для каждого: `verified/violated/unresolved/not_applicable`, ссылки на записи, проверяемое основание |
| `findings` | ID, код, ссылки на записи, наблюдаемый факт, нарушенное условие, тип недостатка, `is_defensible`, первопричина и её последствия |
| `answer` | `written/absent/ambiguous`; буквальный ответ; сравнение с эталоном; запрещённые значения; различия в допустимых границах |
| `unresolved` | Существенные неясности чтения или математики. Открытые S01–S03 отмечать отдельно от неясности фактов |

## Содержание и оформление

| `is_defensible` | Значение |
| --- | --- |
| `true` | Математика выполнена верно, недостаёт её записи; достаточно аккуратно изложить то же уже сделанное рассуждение |
| `false` | Нужны новое рассуждение, исправление вычисления/правила или восстановление решения |

Признак опирается на записи, не на совпадение ответа, и сам по себе не назначает балл.
