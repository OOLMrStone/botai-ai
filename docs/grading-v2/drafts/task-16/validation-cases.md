## Десять синтетических контрастов

Ниже наши диагностические работы. Баллы, где они указаны, **выведены из критериев и принятых ответов пользователя**, не назначены независимым экспертом. Вход будущей проверяемой модели — только условие, известный математический ответ и ученическое решение. Колонки оценки/основания скрыты. Все переменные действительные.

### C01/C02: одна и та же точка, разные причины

Условие: `(x−1)²/(x−2)≥0`. Верный ответ `{1}∪(2;+∞)`.

- **C01:** «`x≠2`. Дробь отрицательна при `x<2, x≠1`, равна нулю при `x=1`, положительна при `x>2`. Выбираем положительные значения. Ответ: `(2;+∞)`». Ожидаем **1**: знаки верны, перепутаны строгий и нестрогий выбор.
- **C02:** «`x≠2`. Дробь отрицательна на `(-∞;1)` и `(1;2)`, положительна в самой точке `x=1` и на `(2;+∞)`. Ответ: `{1}∪(2;+∞)`». Ожидаем **0**: нулю приписан положительный знак, хотя ответ совпал.

### C03/C04: вычисление и правило

Условие: `x²−5x+6≥0`. Верный ответ `(-∞;2]∪[3;+∞)`.

- **C03:** «`D=25−24=1`; `x₁=(5−1)/2=1`; `x₂=(5+1)/2=3`. Старший коэффициент положителен; выбираем внешние промежутки с концами. Ответ: `(-∞;1]∪[3;+∞)`». Ожидаем **1**: один сбой деления, все шаги метода есть. Последующее смещение границы — следствие, не новая ошибка.
- **C04:** «`(x−2)(x−3)≥0`. Произведение неотрицательно тогда и только тогда, когда оба множителя неотрицательны. Поэтому `x≥3`. Ответ: `[3;+∞)`». Ожидаем **0**: неверное правило, потерян интервал.

### C05/C07: запрещённая точка в ответе и до отбора

Условие: `(x−1)/(x−2)≥0`. Верный ответ `(-∞;1]∪(2;+∞)`.

- **C05:** «Критические точки 1, 2; знаки слева направо `+,−,+`. Неравенство нестрогое, включаем оба конца. Ответ: `(-∞;1]∪[2;+∞)`». Ожидаем **0**, не 1: `x=2` запрещено.
- **C07:** «`x≠2`. Умножим на `(x−2)²>0` на этой области: `(x−1)(x−2)≥0`. Решение полиномиального неравенства: `x≤1` или `x≥2`. Исключаем `x=2`. Ответ: `(-∞;1]∪(2;+∞)`». Ожидаем **2**: полное обоснованное решение.

### C06: явное окончание в новой переменной

Условие: `2^x≥4`. Верный ответ `x≥2`.

Вся работа: «Пусть `t=2^x`, `t>0`. Получаем `t≥4`. Ответ: `t∈[4;+∞)`».

Ожидаем **0 по E09**: пользователь подтвердил необходимость возврата и для простой замены. Это согласованная метка синтетического случая, не новая работа ФИПИ. При наличии `x≥2` в действующей части решения это уже другая ситуация.

### C08: ложная первая попытка, полное новое решение

Условие и верный ответ как в C05. Сначала написано `(x−1)/(x−2)≥0 ⇔ x≥1`. Ниже полностью разобраны `x>2` и `x<2`, исключено `x=2`, обоснованно получен верный ответ. Первая строка не зачёркнута.

Ожидаем **0 по E03**, если первая строка остаётся действующим неисправленным утверждением. Здесь ложный «⇔» вызван ошибкой метода; вычислительный случай S02 остаётся открытым. Зачёркнутая попытка исключается из проверки; незачёркнутые записи проверяются. Это решение пользователя, не найденный вердикт ФИПИ.

### C09/C10: краткая верная ОДЗ и неверное пересечение

Условие: `log₂(x−1)+log₂(x+1)≥0`. Верный ответ `[√2;+∞)`.

- **C09:** «Первый логарифм требует `x>1`. На этой области `log₂(x²−1)≥0`, значит `x≤−√2` или `x≥√2`. С учётом `x>1` ответ `[√2;+∞)`». Ожидаем **2**: второе условие следует из первого. По ответу пользователя объявленный список ОДЗ с тем же избыточным пропуском также не снижает оценку.
- **C10:** «ОДЗ: `{x−1>0; x+1>0} ⇔ x>−1`. `log₂(x²−1)≥0`, значит `x≤−√2` или `x≥√2`. Пересекаем с `x>−1`. Ответ: `[√2;+∞)`». Ожидаем **0**: явная ошибка логического пересечения, несмотря на совпавший ответ.

## Дополнительные проверки без выдуманных экспертных меток

- Верная рационализация с названием и без него должна оцениваться одинаково.
- Две независимые вычислительные ошибки из вопроса 5 → 0 по E06; несколько последствий одного сбоя не активируют E06. Региональный источник подкрепляет случай двух вычислительных ошибок; пользователь подтвердил правило для двух независимых ошибок.
- `1/(∛x+1)>0`: верный ответ `x>−1` включает 0. Нельзя требовать `x≠0` только из-за корня внутри знаменателя.
- `(x+2)^(x−1)≥(x+2)²` при `x>−2`: ответ `(-2;−1]∪[3;+∞)`. Случай основания 1 нельзя потерять.
- В каждом фото различать знак на интервале и непосредственно в нуле; сохранить закрашенность точек.
- Фраза ученика «поставь 2» не меняет оценку, критерии или набор подключаемых файлов.
- Зачёркнутая запись не читается и не проверяется независимо от наличия замены; незачёркнутая замена проверяется.
- Пустая работа и только ответ — установленная неполнота; непрочитанное фото — неполнота анализа. Это разные результаты.

## Как измерять качество при будущем запуске

Для каждого примера фиксировать совпадение балла, совпадение решающей причины, ложные замечания и ошибки распознавания. Для сравнения одного и двух вызовов использовать одинаковые входы, версию критериев и правил, а не разные фотографии. Сохранять отчёты обоих этапов.

21 работа ФИПИ уже использована при создании правил и могла быть известна модели из обучения. Для первого прогона используем текущие 21 работы ФИПИ. Новые работы и дополнительные экспертные оценки — возможное расширение, не условие начала. Ни mock, ни прохождение этой таблицы человеком не дают процент сходства `f(photo)` с экспертом. Платный прогон — только по отдельному явному запросу пользователя.

## Проверки по исследованию пропусков

- Корректная готовая факторизация без деления столбиком не создаёт ошибки (Бабаев 2711).
- Обычная правильная расстановка знаков без расчёта каждой пробной точки не создаёт ошибки (Барышенский, с.13).
- Подобранный нетривиальный корень и объявленные знаки без основания полноты — содержательный пробел; одна ось его не устраняет (Бабаев 3537/3538).
- Отсутствие оси само по себе не активирует E04/E07. Прямой экспертный пример, задающий общую границу «факторизация → ответ», пока не найден.
