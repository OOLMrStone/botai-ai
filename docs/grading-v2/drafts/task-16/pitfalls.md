# Неравенства: ошибки и оценка

## Общие ошибки — 0 баллов

| Код | Ошибка |
| --- | --- |
| E01 | В окончательный ответ включено значение вне области определения исходного неравенства |
| E02 | Явно заявлена ложная ОДЗ из-за неверных условий или логики их объединения. Вычислительная ошибка в ОДЗ — S01 |
| E03 | Ложный «⇔» из-за неверного метода или строгости. Поздний отбор не исправляет это утверждение. Вычислительный сбой — S02 |
| E04 | Пропущены значительные шаги вычисления: даже при благожелательном чтении логику переходов нельзя проследить, переходы слишком резкие |
| E05 | Неверно применено действие или математическое правило |
| E06 | Две или более независимые вычислительные ошибки |

## Логарифмы и степени — 0 баллов

| Код | Ошибка |
| --- | --- |
| E16 | При сравнении логарифмов или степеней с основанием `0<a<1` не изменён знак неравенства |
| E17 | При сравнении логарифмов или степеней с основанием `a>1` знак неравенства изменён |
| E18 | Для переменного основания пропущен возможный случай `0<a<1` или `a>1` |
| E19 | При сравнении степеней потерян допустимый случай основания `a=1` |
| E20 | Логарифм произведения разложен в сумму логарифмов неположительных множителей |
| E21 | В `log_a(u²)=2log_a(abs(u))` отброшен модуль при допустимых отрицательных `u` |

| E27 | Недостижимые значения новой переменной приняты как допустимые. Например, при `t=√x` ветвь `t≤−1` обращена в `x≥1` |

## Рационализация — 0 баллов

| Код | Ошибка |
| --- | --- |
| E30 | Замена не сохраняет знак на ОДЗ. Например, `log_(1/2)(x)≥0` заменено на `x−1≥0` вместо `x−1≤0` |
| E31 | Замена не сохраняет нули. Например, нуль `log₂(x)` при `x=1` заменён нулём `x−2` при `x=2` |
| E32 | По совпадению знаков заменены отдельные слагаемые; получено неравносильное неравенство |
| E33 | Совпадение знаков принято за равенство выражений. Например, записано `log₂(x)=x−1` |
| E34 | Замена по знаку применена при сравнении с ненулевой величиной. Например, `log₂(x)≥2` заменено на `x−1≥2` |

## Спорные ситуации

| Код | Ситуация | Пример | Решение |
| --- | --- | --- | --- |
| S01 | Вычислительная ошибка в ОДЗ при верно записанных условиях существования | Например, из `x+6≠1` получено `x≠1−6=−7` | `<решение не принято>` |
| S02 | Вычислительная ошибка сделала ложным переход со знаком «⇔» | Например, `2x≥6 ⇔ x≥2` | `<решение не принято>` |
| S03 | Всё решение верно, но окончательный ответ переписан неверно | Например, получено `(-∞;1]∪(2;+∞)`, а в ответе `(-∞;−1]∪(2;+∞)` | `<решение не принято>` |

## Не ошибка — при остальном верном решении 2 балла

| Ситуация |
| --- |
| Пропущены некоторые незначительные шаги вычисления; логику можно проследить, этапы решения и ответ верные |
| Ограничения учтены без отдельного заголовка «ОДЗ» |
| При вычислении верной ОДЗ не повторено избыточное условие |
| Диапазон замены учтён при возврате, но не выписан отдельно |
| Готовая правильная факторизация записана без деления многочлена |
| При обычном корректном методе интервалов не расписан расчёт каждого знака |
| Достаточное обоснование дано формулами или осью без словесного пересказа |
| Использован другой корректный метод или эквивалентная форма ответа |
| Не выписаны очевидные условия для постоянного основания |
