# Общие правила проверки

| Правило | Применение |
| --- | --- |
| Вычислительная ошибка | Неверно полученное число в результате верного действия |
| Ошибка метода | Неверное действие, правило или условие его применения |
| Первопричина | Классифицировать причину, а не её последствия. Пропавший из-за вычисления интервал не становится отдельной ошибкой метода или незавершённостью |
| Независимость ошибок | Одна причина и её последствия считаются одной ошибкой |
| Полнота решения | Учесть отбор и случаи, разобранные позднее. Сам по себе правильный итог не отменяет оставшееся ложное утверждение |
| Оценка всей работы | Баллы не складываются и не вычитаются за отдельные замечания |
| Условие для 1 балла | Остальные шаги верны для полученных данных и доведены до конца; нет независимого основания для 0 |
| Совпавший ответ | Не отменяет оставшуюся ошибку. Одна вычислительная ошибка — 1, несколько независимых — 0; S01/S02 пока открыты |
| Приоритет запрета | Запрещённое значение в окончательном ответе даёт 0 независимо от причины его появления |
| Открытая трактовка | S01–S03: `<решение не принято>`. Общее правило не подставляет за них 0 или 1 |
| Равносильность | Проверять на действующих ограничениях и в рассматриваемой ветви |
| Следствие | Допустимо с полным отбором по исходной задаче; отбор не восстанавливает потерянные решения |
| Обоснованность | Для замечания назвать конкретный недоказанный вывод. Отсутствие названия метода, оси или промежуточного вычисления само по себе не доказывает пробел |
| Полный интервал | Подстановка нескольких произвольных значений не доказывает весь интервал. Пробная точка допустима при установленных нулях, разрывах и постоянстве знака между ними |
| Строгость | Одна ошибка строгости может затронуть несколько допустимых граничных точек |
