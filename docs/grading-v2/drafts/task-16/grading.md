# Выставление балла

## Порядок

| Шаг | Действие |
| --- | --- |
| Полнота анализа | Проверить транскрипцию, четыре проверки, ответ либо его отсутствие и основания замечаний. Пустой список ошибок не доказывает 2 балла |
| Противоречия | Уточнить факты по фото и обновить анализ. Недостаток данных анализа не считать недостатком работы ученика |
| Классификация | Использовать зафиксированные причины. Не менять `is_defensible` без исправления самого анализа |
| Оценка | Выбрать одну строку `criteria.md` с учётом `rules.md` и `pitfalls.md`. Индивидуальные критерии задачи имеют приоритет |
| Открытый случай | S01–S03: `<решение не принято>`. Их числовой результат и способ выдачи пока не определены. Независимое установленное основание для 0 сохраняет силу |
| Ученический ответ | После фиксации оценки подготовить объяснение по `feedback.md` и отдельные советы по `advice.md` и `advice-catalog.md` |

## Результат вне открытых S01–S03

| Поле | Содержание |
| --- | --- |
| `status` | `graded` либо `needs_clarification` при существенной неясности фактов |
| `score` | 0, 1 или 2 при `graded`; иначе `null` |
| `criterion` | Применённая строка критериев; версия правил `task16-v3` |
| `evidence` | ID решающих записей/замечаний; короткое основание балла |
| `feedback` | Объяснение выбранной оценки |
| `advice` | 0–2 совета; поля элемента: `tip_id`, `fact_refs`, `title`, `text` |
| `clarification` | Конкретный вопрос о недостающем факте; иначе пусто |

При `needs_clarification`: `feedback` пуст, `advice` — пустой список. Чётко прочитанное незаконченное решение оценивается по критериям, а не получает этот статус.
