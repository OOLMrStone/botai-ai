# Экспертные примеры: неравенства

21 работа из пользовательского PDF `matematika_mr_ege_2026.pdf`, с. 90–110: 15.1.1–15.6.2. Номер задачи в источнике — 15, в новой структуре проекта — 16. Источник: [методические материалы ФИПИ 2026](https://doc.fipi.ru/ege/dlya-predmetnyh-komissiy-subektov-rf/2026/matematika_mr_ege_2026.pdf).

Модели передаются изображение условия с известным ответом из `problems/` и `solution.png` выбранного примера. Рукописное решение вырезано из PDF без исправлений; комментарий и балл эксперта в него не попали. `expected.json`, этот файл и служебные метаданные модели не передаются. Балл и комментарий сравнивает человек с итогом модели; автоматическая оценка качества сейчас не реализуется.

`expected.json`: `score` — балл эксперта, `verdict` — его комментарий. Переносы строк убраны; в 15.2.4 математическая формула из комментария переписана в линейную запись. `manifest.json` связывает изображения, эталон и страницу источника. Известный ответ включён во вход намеренно: это соответствует входу продукта.

## Границы набора

Это принятый рабочий набор из 21 оценённой ФИПИ работы для первых эвалов и сравнения версий промптов. Из источника извлекались общие правила, а не специальные ответы на отдельные фото. Набор пригоден для проверки; результаты описывают качество на этих 21 работах, а не автоматически на всех возможных работах ЕГЭ. Проверка человеком должна учитывать не только совпадение балла, но и причину: например, ноль в 15.3.4 должен объясняться ошибкой в системе ОДЗ, а не придуманной ошибкой распознавания.

В этих 21 примерах нет отдельного образца на 1 балл именно за вычислительную ошибку; соответствующее правило берётся из общей таблицы с. 83. Не приписывать такой паттерн произвольной работе ради полноты набора.
