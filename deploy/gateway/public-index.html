BotAI: проверка решений

Здесь — инструкция по работе с основным сервисом и тестовой версией DEVELOP. Данные для входа выдаёт администратор лично.

Проверить решение

  1. Откройте основной сервис или DEVELOP.
  2. Введите выданные вам логин и пароль. Для каждой версии используйте выданный ей доступ.
  3. Прикрепите одно изображение с условием и правильным ответом, затем от одной до четырёх фотографий решения ученика. Размер каждого файла — до 8 МБ.
  4. Нажмите «Проверить». Проверка может занять до шести минут. Если произошла ошибка, оценка не выставляется.

Работа разработчика · DEVELOP

Администратор выдаёт адрес, имя пользователя и доступ к отдельной копии сервиса. Создайте личный SSH-ключ и передайте администратору только публичную часть — файл с окончанием .pub. Приватный ключ никому не отправляйте.

ssh -i "ключ" "пользователь@адрес"

В примере ключ — путь к вашему приватному SSH-ключу; пользователь и адрес — значения из личной инструкции. При первом входе сверьте отпечаток сервера с администратором.

После подключения откройте папку проекта из личной инструкции. Загрузите туда изменения через SFTP или SCP, сохраняя локальные настройки подключения. Пересоберите свою версию:

docker compose up -d --build
docker compose ps
docker compose logs --tail=100 develop

Для открытия DEVELOP запустите на своём компьютере отдельный SSH-туннель и оставьте терминал открытым:

ssh -i "ключ" -N -L "127.0.0.1:локальный-порт:127.0.0.1:порт-сервиса" "пользователь@адрес"

Значения портов указаны в личной инструкции. В браузере откройте http://127.0.0.1:локальный-порт/ui/. Туннель разрешён только к DEVELOP. Остановить его можно нажатием Ctrl+C. Обычный push в Git сам по себе не обновляет сервис.

Доступ к модели

Тестовая версия обращается к модели через отдельный шлюз. Настоящий ключ провайдера разработчику не выдаётся. Количество вызовов не ограничено; при одновременной нагрузке запрос может получить сообщение о занятости — повторите его позже.

На этой странице нет персональных данных, ключей, паролей и внутренних настроек. Если браузер просит войти, используйте доступ, выданный администратором; SSH для обычной проверки решений не нужен.
