# Уравнения с отбором корней: ошибки и оценка

Ошибка не из раздела «Вычислительная ошибка» снижает балл, даже если не повлияла на ответ: допущена в ветви, которая дальше отброшена, в ОДЗ или в шаге, который дальше не используется. Например, `log₄ y = 2 ⇒ y = 8` в ветви, отброшенной по условию `abs(sin x) ≤ 1`, — 0 баллов.

## Пункт а: общие ошибки — 0 баллов

| Код | Ошибка | Совет |
| --- | --- | --- |
| E01 | В работе нет ответа на вопрос пункта а: решение не доведено до серий корней или серии не выписаны, даже если пункт б выполнен верно | Всегда доводи пункт а до всех серий корней с параметром: без ответа пункта а задание оценивается в 0 баллов даже при верном отборе. |
| E02 | Ученик решил другое уравнение вместо заданного | Перед решением сверь переписанное уравнение с условием: коэффициенты, знаки, степени и аргументы функций. |
| E03 | Пропущено существенное рассуждение, без которого модель вынуждена сама восстанавливать метод или этап решения | *Для модели: укажи конкретный непонятный переход и предложи короткую промежуточную запись, которая делает ход решения прослеживаемым.* |
| E04 | Неверный переход из-за ошибочной формулы или правила, для которого ниже нет отдельного кода. Например, в формуле корней квадратного уравнения в знаменателе `2` вместо `2a`. Верный итоговый ответ не исправляет такой переход | *Для модели: назови неверно применённую формулу и покажи правильный переход на выражении ученика.* |

## Простейшие тригонометрические уравнения — 0 баллов

| Код | Ошибка                                                                                                                                                     | Совет                                                                                                                                      |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| E05 | В решении `sin x = a` потеряна одна из двух серий. Например, `sin x = 1/2 ⇒ x = π/6 + 2πn` без серии `5π/6 + 2πn`                                          | Запомни: при `abs(a) < 1` у `sin x = a` две серии на периоде `2π`, или одна запись `x = (−1)ⁿ arcsin a + πn`.                              |
| E06 | В решении `cos x = a` потерян знак `±`. Например, `cos x = 1/2 ⇒ x = π/3 + 2πn`                                                                            | Запомни: `cos x = a ⇒ x = ±arccos a + 2πn`. Сверяй обе точки на окружности.                                                                |
| E07 | В решении `sin x = a` или `cos x = a` при `0 < abs(a) < 1` серия записана с периодом `π` вместо `2π`. Например, `cos x = 1/2 ⇒ x = ±π/3 + πn` | Запомни: у синуса и косинуса период `2π`; период `π` бывает только в частном случае значения `0`. Сверяй серию с точками на окружности. |
| E08 | Частный случай `sin x` или `cos x`, равных `0` или `±1`, записан с неверным периодом. Например, `sin x = 1 ⇒ x = π/2 + πn` или `cos x = 0 ⇒ x = π/2 + 2πn` | Запомни: при значении `±1` одна серия с периодом `2π`, при значении `0` — одна серия с периодом `π`. Сверяй серию с точками на окружности. |
| E09 | В решении `tg x = a` или `ctg x = a` период `2π` вместо `π`. Например, `tg x = 1 ⇒ x = π/4 + 2πn`                                                          | Запомни: у тангенса и котангенса период `π`.                                                                                               |
| E10 | Арккосинус отрицательного числа записан как минус арккосинус. Например, `arccos(−1/2) = −π/3` вместо `2π/3`                                                | Запомни: `arccos(−a) = π − arccos a`, значения арккосинуса лежат в `[0; π]`.                                                               |
| E11 | Выписана серия для `sin x = a` или `cos x = a` при `abs(a) > 1`. Например, `x = (−1)ⁿ arcsin 2 + πn`                                                       | Запомни: синус и косинус принимают значения только из `[−1; 1]`, такое уравнение корней не имеет.                                          |

## Тригонометрические формулы — 0 баллов

| Код | Ошибка | Совет |
| --- | --- | --- |
| E12 | В формуле приведения неверный знак или не сменена функция. Например, `sin(3π/2 + x) = cos x` вместо `−cos x` | Определи знак по исходной функции в нужной четверти, функцию меняй при `π/2` и `3π/2`. |
| E13 | Неверная формула двойного угла. Например, `sin 2x = 2 sin x` или `cos 2x = 1 − 2cos²x` | Запомни: `sin 2x = 2 sin x cos x`, `cos 2x = cos²x − sin²x = 2cos²x − 1 = 1 − 2sin²x`. |
| E14 | Неверно применено основное тригонометрическое тождество. Например, `cos²x = 1 + sin²x` | Запомни: `sin²x + cos²x = 1`, отсюда `cos²x = 1 − sin²x`. |

## Деление, сокращение и разложение на множители — 0 баллов

| Код | Ошибка | Совет |
| --- | --- | --- |
| E15 | Обе части уравнения разделены или сокращены на выражение с переменной, а случай, когда это выражение равно нулю, не рассмотрен; из-за этого потеряна серия. Например, `sin x·cos x = sin x` разделено на `sin x` без отдельного решения `sin x = 0`. Деление с отдельно рассмотренным нулевым случаем — не ошибка | Перед делением на выражение с переменной реши отдельно уравнение «выражение = 0» или вынеси общий множитель за скобки: каждый множитель даст свою серию. |
| E16 | Неверное разложение на множители или вынесение общего множителя: потерян знак, множитель или слагаемое. Например, `2 sin x(cos x − 1) + cos x − 1 = 0` записано как `(2 sin x − 1)(cos x − 1) = 0` вместо `(2 sin x + 1)(cos x − 1) = 0`. Это ошибка преобразования, а не вычислительная | Проверяй разложение обратным раскрытием скобок: должно получиться исходное выражение. |

| Код | Ошибка                                                                                                                                                                         | Совет                                                                                                    |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------- |
| E17 | Не отброшено значение новой переменной, которого она не может принимать. Например, при `t = sin x` из `t = 2` выписана серия, при `t = 2ˣ` из `t = −3` записано `x = log₂(−3)` | Перед возвратом к x сверь каждое значение `t` с областью значений замены.                                |
| E18 | Нет возврата от новой переменной к x: ответ пункта а записан значениями `t`                                                                                                    | Запомни: ответ пункта а всегда пишется для x.                                                            |

## Логарифмы и степени — 0 баллов

| Код | Ошибка | Совет |
| --- | --- | --- |
| E19 | Неверный переход от простейшего логарифмического уравнения к аргументу: `log_a y = b` решено как `y = a·b` или `y = bᵃ` вместо `y = aᵇ`. Например, `log₄ y = 2 ⇒ y = 8`. Это ошибка в правиле, а не вычислительная | Запомни: `log_a y = b ⇔ y = aᵇ`. Проверь подстановкой: `log₄ 16 = 2`, потому что `4² = 16`. |
| E20 | Свойство логарифма применено к множителю, который может быть отрицательным, и из-за этого потеряны или приобретены корни. Например, `log₂(x²) = 2log₂ x` | Запомни: `log_a(u²) = 2log_a(abs(u))` при `u ≠ 0`. |
| E21 | Неверное свойство логарифма. Например, `log₂ x + log₂ 3 = log₂(x + 3)` | Запомни: `log_a u + log_a v = log_a(uv)` при `u > 0` и `v > 0`. |
| E22 | Неверное свойство степени. Например, `2ˣ·2ˣ = 2^(x²)` или `4ˣ = 2^(x+2)` | Запомни: `aᵘ·aᵛ = a^(u+v)`, `(aᵘ)ᵛ = a^(uv)`, `4ˣ = 2^(2x)`. |

## ОДЗ — 0 баллов

| Код | Ошибка                                                                                                                                                                        | Совет                                                                       |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| E23 | В ответ пункта а вошли значения, при которых уравнение не имеет смысла: знаменатель, `cos x` при `tg x`, аргумент логарифма или подкоренное выражение вне допустимых значений | Выпиши ограничения до решения и отбрось серии, которые им не удовлетворяют. |
| E24 | ОДЗ составлена неверно: пропущено условие, записан не тот знак или не то условие. Например, для `log_(x−1) 5` нет условия `x − 1 ≠ 1`, для `log₂(x + 3)` записано `x + 3 ≥ 0` вместо `x + 3 > 0`, для `tg x` записано `sin x ≠ 0` вместо `cos x ≠ 0` | Для каждой функции выпиши её условие: знаменатель `≠ 0`, аргумент логарифма `> 0`, основание логарифма `> 0` и `≠ 1`, подкоренное выражение `≥ 0`, для `tg x` — `cos x ≠ 0`, для `ctg x` — `sin x ≠ 0`. |
| E25 | Условия ОДЗ записаны верно, но решены по неверному правилу. Например, `x² > 4 ⇒ x > 2` без `x < −2`. Ошибка в счёте при верном правиле — вычислительная (раздел «Вычислительная ошибка») | Решай условия ОДЗ так же аккуратно, как само уравнение, и проверяй найденные границы подстановкой. |

## Параметр серии — 0 баллов

| Код | Ошибка | Совет |
| --- | --- | --- |
| E26 | Существует хотя бы один введённый параметр серии корней, для которого ни разу не указано, какому множеству он принадлежит | Указывай, что параметр целый: достаточно один раз записать `n ∈ Z` для всех серий. |

## Отбор корней (пункт б) — 1 балл при верном пункте а

| Код | Ошибка | Совет |
| --- | --- | --- |
| E28 | На окружности не подписаны концы отрезка: точки отмечены без значений или не отмечены вовсе. Значения, вычисленные рядом с окружностью, подписи на ней не заменяют: отбор не обоснован и при верном ответе | Подпиши оба конца отрезка их значениями из условия пункта б. |
| E29 | На окружности не выделена дуга между концами отрезка | Выдели дугу жирной, двойной или волнистой линией. |
| E30 | Отобранные корни на дуге не подписаны значениями. Например, у точек стоят только номера серий: номер серии из пункта а корень не обозначает. Вычисления рядом с окружностью (`−π/4 − 2π = −9π/4`) подписи на ней не заменяют: отбор не обоснован и при верном ответе | Подпиши каждый корень на дуге его значением. |
| E31 | При переборе значений параметра перебор остановлен на корне отрезка, в том числе совпавшем с его концом: не показано значение серии за границей отрезка | При переборе дойди до значения, которое лежит за концом отрезка, с обеих сторон. |
| E32 | При отборе без окружности корень сравнён только с одной границей отрезка | Для каждого корня покажи оба неравенства: с левым и с правым концом. |
| E33 | В ответ пункта б или на дугу включён корень, который лежит вне отрезка, не из-за вычислительной ошибки | Проверь каждый корень ответа: он лежит между концами отрезка. |
| E34 | В ответ пункта б не вошёл корень, который лежит на отрезке, не из-за вычислительной ошибки | Пройди по каждой серии пункта а и проверь все её значения на отрезке. |
| E35 | Точка на окружности подписана неверным значением или номер корня стоит не у своей точки | Сверь каждую подпись с серией пункта а и с положением точки на окружности. |
| E36 | В ответ пункта б записано число, которое не является корнем уравнения: его нет в сериях пункта а | Каждый корень ответа найди в одной из серий пункта а. |
| E37 | Верные корни получены через неверную строку отбора: неверная граница двойного неравенства, ошибка деления, неверно найденное `n` | Проверь каждую строку отбора: верный корень после неверной строки отбор не обосновывает. |
| E38 | Корни пункта б указаны без отбора: способ отбора не показан | Покажи отбор явно: окружность с обязательными отметками, двойное неравенство или перебор для каждой серии. |
| E39 | Пункт б не выполнен или не доведён до ответа | Даже без полного отбора начни с окружности: отметь концы отрезка и точки серий из пункта а. |

## Вычислительная ошибка — 1 балл

| Код | Ошибка | Совет |
| --- | --- | --- |
| E40 | В пункте а, в том числе при решении ОДЗ, неверно вычислено значение числа, степени, логарифма или тригонометрической функции при верной последовательности всех шагов. Например, `8^(1/2) = 4`. Неверная формула или правило — не вычислительная ошибка, а E04 или код из разделов выше | *Для модели: покажи верное действие на числе ученика и короткий способ проверки, например подстановку корня.* |
| E41 | После замены (новая переменная, обычно `t`: `t = sin x`, `t = 2ˣ`, `t = log₂ x`) вспомогательное уравнение для `t` составлено верно, но его корень найден неверно из-за арифметики. Например, ошибка в дискриминанте. Неверная формула корней — E04 | Подставь найденные значения `t` во вспомогательное уравнение до возврата к x. |
| E42 | Способ отбора и серии пункта а верны, но при отборе неверно вычислено значение корня или границы, и из-за этого в ответ пункта б попал неверный корень или потерян верный. Например, при `n = 2` значение `π/6 + 2πn` записано как `13π/6` вместо `25π/6` | Для каждого корня ответа пересчитай значение серии при найденном `n`. |
| E43 | Корни верно получены в решении, но в ответ перенесены с ошибкой: описка в числе, знаке или знаменателе | Сверяй строку ответа с последними строками решения. |

## Не ошибка — при остальном верном решении 2 балла

| Ситуация |
| --- |
| Множество корней записано в другой эквивалентной форме: объединённые серии, `±`, `(−1)ⁿ` |
| Серии записаны с дублированием: одна серия содержится в другой |
| Отбор выполнен корректно, обоснованно, но другим способом. Например, двойным неравенством или перебором значений параметра вместо тригонометрической окружности |
| На окружности дополнительно отмечены вспомогательные точки отрезка |
| Конец отрезка совпал с отобранным корнем и подписан одной подписью этого корня |
| Корень на окружности обозначен именем (`x₁`, `A`), а его значение записано рядом с этим именем |
| Для всех серий введён один параметр или для каждой серии свой |
| Один параметр `n` использован в нескольких сериях, и `n ∈ Z` записано один раз для всех этих серий |
| Без доказательства и ссылки использован факт из школьного учебника: формулы приведения, формулы корней простейших тригонометрических уравнений, свойства степеней и логарифмов |
| Ограничения учтены без отдельного заголовка «ОДЗ» |
| Ответ не вынесен отдельной строкой, но все серии пункта а и корни пункта б явно получены в решении |
| Неточность записи, при которой все записанные и вычисленные значения верны. Например, дискриминант и корень из него объединены в одной цепочке равенств. Неверное число в строке отбора — не неточность, а ошибка (E37) |
| Отдельные простые переходы выполнены в уме, но по записанному решению ход рассуждений ясно прослеживается |
