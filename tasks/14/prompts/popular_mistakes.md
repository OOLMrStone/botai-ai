# Уравнения с отбором корней: ошибки и оценка

## Решение уравнения (пункт а) — 0 баллов

| Код | Ошибка | Совет |
| --- | --- | --- |
| E01 | Решение пункта а не доведено до серий корней, даже если пункт б выполнен верно | Всегда доводи пункт а до всех серий корней с параметром: без ответа пункта а задание оценивается в 0 баллов даже при верном отборе. |
| E02 | Неверно решено простейшее уравнение: неверная серия, потеряна одна из двух серий или период. Например, `sin x = 1 ⇒ x = π/2 + πn` | Запомни: при `sin x` или `cos x`, равных ±1, одна серия с периодом `2π`, равных 0 — одна серия с периодом `π`. Сверяй серию с точками на окружности. |
| E03 | При делении или сокращении на выражение с переменной потеряна серия. Например, `sin x·cos x = sin x` разделено на `sin x` | Не дели на выражение с переменной: перенеси всё в одну часть и вынеси общий множитель — каждый множитель даст свою серию. |
| E04 | Неверный переход из-за ошибочной формулы или правила. Например, потерян минус в формуле приведения или в формуле корней квадратного уравнения в знаменателе `2` вместо `2a` | *Для модели: назови неверно применённую формулу и покажи правильный переход на выражении ученика.* |
| E05 | После замены не отброшено невозможное значение. Например, из `sin x = 2` выписана серия `x = (−1)ⁿ arcsin 2 + πn` | Сверяй найденные значения новой переменной с областью значений функции до возврата к x. |
| E06 | В ответ пункта а вошли значения вне области определения уравнения | Выпиши ограничения до решения и отбрось серии, которые им не удовлетворяют. |
| E07 | Неверно составлена или решена ОДЗ не из-за вычислительной ошибки | Проверяй найденные ограничения подстановкой в исходное уравнение. |
| E08 | Ученик решил другое уравнение вместо заданного | Перед решением сверь переписанное уравнение с условием: коэффициенты, знаки, степени и аргументы функций. |
| E09 | Ни в одном месте решения не указано, какому множеству принадлежит параметр серии корней | Указывай, что параметр целый: достаточно один раз записать `n ∈ Z` для всех серий. |

## Отбор корней (пункт б) — 1 балл при верном пункте а

| Код | Ошибка | Совет |
| --- | --- | --- |
| E10 | На окружности нет обязательных отметок: не обозначены концы отрезка, не выделена дуга или не обозначены отобранные корни. Например, у точек на дуге стоят только номера серий | На окружности подпиши оба конца отрезка, выдели дугу между ними и подпиши каждый корень на дуге — без этого отбор не засчитывается. |
| E11 | Не показано, что корень лежит в отрезке с обеих сторон: перебор остановлен на корне отрезка, в том числе совпавшем с его концом, или при проверке без окружности корень сравнён только с одной границей | Для каждого корня покажи обе границы: при переборе — значения серии за обоими концами отрезка, при сравнении — оба неравенства. |
| E12 | Неверный состав ответа пункта б не из-за вычислительной ошибки: на дуге отмечен корень вне отрезка, точка подписана неверным значением или номер корня стоит не у своей точки, в ответе число, не являющееся корнем уравнения | Проверь каждый корень ответа: он принадлежит серии пункта а и лежит между концами отрезка. |
| E13 | Корни пункта б указаны без отбора: способ отбора не показан | Покажи отбор явно: окружность с обязательными отметками или двойное неравенство для каждой серии. |
| E14 | Пункт б не выполнен или не доведён до ответа | Даже без полного отбора начни с окружности: отметь концы отрезка и точки серий из пункта а. |

## Вычислительная ошибка — 1 балл

| Код | Ошибка | Совет |
| --- | --- | --- |
| E15 | Неверные ответы из-за вычислительной ошибки в пункте а, при отборе корней или при переносе в ответ, при верной последовательности всех шагов обоих пунктов. Например, `8^(1/2) = 4` или неверно вычислен корень `t` верно составленного квадратного уравнения. Исключение — неверная формула или правило (E04) | *Для модели: покажи верное действие на числе ученика и короткий способ проверки, например подстановку корня.* |

## Не ошибка — при остальном верном решении 2 балла

| Ситуация |
| --- |
| Множество корней записано в другой эквивалентной форме: объединённые серии, `±`, `(−1)ⁿ` |
| Серии записаны с дублированием: одна серия содержится в другой |
| Отбор выполнен любым корректным способом |
| На окружности дополнительно отмечены вспомогательные точки отрезка |
| Один параметр для всех серий или свой для каждой; `n ∈ Z` записано один раз для нескольких серий |
| Ограничения учтены без отдельного заголовка «ОДЗ» |
| Ответ не вынесен отдельной строкой, но все серии пункта а и корни пункта б явно получены в решении |
| Неточность записи, при которой все вычисленные значения верны. Например, дискриминант и корень из него объединены в одной цепочке равенств |
| Отдельные простые переходы выполнены в уме, но по записанному решению ход рассуждений ясно прослеживается |
