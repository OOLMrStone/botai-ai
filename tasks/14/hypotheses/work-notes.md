## Правила (от Кости и руководителя) — соблюдать всегда

- **ФИПИ важнее всего.** Ошибку можно вносить в справочник, если она подтверждена реальной оценённой работой или документом предметной комиссии и **не противоречит ФИПИ**. Мнение школы без оценённой работы — только повод для вопроса. Решения руководителя (см. history 30.09) важнее и ФИПИ.
- **Агенты спорят:** исследователи предлагают → агент-критик атакует каждое предложение по первоисточникам → возражения возвращаются исследователям → несогласованное — вопрос Косте.
- **Сомневаешься — спроси**, не делай наугад.
- **Без подписей и атрибуций** в коммитах, PR и документах: никаких строк-подписей и соавторов, кроме самого Кости.
- **Git:** коммит и push — только по явному «да» Кости. **Только обратимое** (Костя, 03.10: «ТОЛЬКО НЕ ДЕЛАЙ НЕОБРАТИМЫХ ДЕЙСТВИЙ… делай только предложения»): push только новых веток, PR — да, merge/close/approve — нет; существующие ветки (`main`, `14-implementation`, `claude/*`) не трогать; никакого force push, amend/rebase после отправки. Merge и деплой на боевой сервер делает руководитель.
- **Платные вызовы модели** — только по явному запросу Кости в текущем сообщении. Локально `LLM_PROVIDER=mock`.
- Тексты и документы — по-русски; код, логи и коммиты — по-английски (AGENTS.md).
- Справочники писать кратко и точно, по образцу задания 16 и `docs/grading/editor-guidelines.md`: один код — одна ошибка; отдельный код, только если другой балл или другой совет; уточнение — только если без него модель ошибётся.
