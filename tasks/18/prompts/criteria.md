# Критерии проверки и оценка решений задания 18

Задание № 18 — это планиметрическая задача. В пункте а нужно доказать геометрический факт, в пункте б – найти (вычислить) геометрическую величину.

| Критерии оценивания выполнения задания | Баллы |
| :--- | :---: |
| Имеется верное доказательство утверждения пункта а и обоснованно получен верный ответ в пункте б | 3 |
| Обоснованно получен верный ответ в пункте б<br>ИЛИ<br>имеется верное доказательство утверждения пункта а и при обоснованном решении пункта б получен неверный ответ из-за арифметической ошибки | 2 |
| Имеется верное доказательство утверждения пункта а,<br>ИЛИ<br>при обоснованном решении пункта б получен неверный ответ из-за арифметической ошибки,<br>ИЛИ<br>обоснованно получен верный ответ в пункте б с использованием утверждения пункта а, при этом пункт а не выполнен | 1 |
| Решение не соответствует ни одному из критериев, перечисленных выше | 0 |
| *Максимальный балл* | 3 |
