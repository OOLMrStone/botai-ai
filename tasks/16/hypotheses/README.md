Первые четыре пункта — наблюдаемые недостатки сохранённого прогона. Предложенные меры пока гипотезы; уборка путей не означает их исправления. Внутреннюю причину модельного пропуска нельзя доказать одним response.json.

Открытый продуктовый вопрос: где хранить совет по точке роста при отсутствии ошибок; не создавать фиктивную ошибку ради заполнения совета. История формата — [for-rating.md](../../../docs/grading/archive/for-rating.md), пользовательские цитаты и предметные контрасты — [work-notes.md](history.md).
