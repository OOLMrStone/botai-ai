# Неравенства: ошибки и оценка

## Общие ошибки — 0 баллов

| Код | Ошибка | Совет |
| --- | --- | --- |
| E01 | В окончательный ответ включено значение вне области определения исходного неравенства. Исключение — E37. | Перед ответом пересеки полученное множество с ОДЗ; отдельно сверь включение граничных точек. Запрещённые точки и промежутки должны остаться исключёнными. |
| E02 | Неверно составлена или вычислена явно записанная ОДЗ, даже если итоговый ответ верен. | Проверяй вычисленные границы ОДЗ подстановкой в исходные условия. Ошибка в ОДЗ может стоить всех баллов даже при верном дальнейшем решении. |
| E03 | Ложный «⇔», кроме вычислительной ошибки (E36). Поздний отбор не исправляет ложное утверждение равносильности. Например, `2x²>x² ⇔ 2>1` без ограничения `x≠0` — 0, даже если 0 исключён позже. | *Для модели: на переходе ученика покажи, почему «⇔» неверен. Если все нужные случаи разобраны далее, покажи запись через «;» с этим разбором: она не заявляет ложную равносильность. Например, `2x²>x²; 2>1; при x≠0 верно, при x=0 неверно`. Если случая или условия нет, сначала восстанови его: смена знака сама по себе ошибку не исправляет.* |
| E04 | Пропущено существенное рассуждение, без которого модель вынуждена самостоятельно восстанавливать метод или этап решения | *Для модели: укажи конкретный непонятный переход и предложи короткую промежуточную запись, которая делает ход решения прослеживаемым.* |
| E05 | Неверный переход из-за ошибочного действия, математического правила или нарушения условий его применения. Верный итоговый ответ не исправляет такой переход | *Для модели: назови неверно применённое правило и покажи правильный переход на выражении ученика, указав необходимое условие его применения.* |
| E06 | Две или более независимые вычислительные ошибки | Обидные ошибки при счете, как правило, уходят с практикой. Запоминай, где чаще всего ошибаешься и перепроверяй себя дотошно в этих местах. Главное - ботай!   |
| E07 | Ученик решил другое неравенство вместо заданного | Перед решением сверь записанное неравенство с условием: числа, знаки, степени и аргументы. |
| E08 | Перепутаны система и совокупность: условия, которые должны выполняться одновременно, объединены знаком совокупности или альтернативные условия — знаком системы. | Запомни: система означает «и», совокупность — «или». Перед объединением условий проверь, должны ли они выполняться одновременно или достаточно одного из них. |

## Незавершённое решение — 0 баллов

| Код | Ошибка | Совет |
| --- | --- | --- |
| E09 | Не разобрана необходимая ветвь решения | *Для модели: выпиши пропущенную ветвь рядом с разобранной и покажи, как коротко обозначить все случаи перед решением.* |
| E10 | Пропущен интервал решений | Отмечай на оси каждый подходящий промежуток, это помогает избежать ошибок. А еще повышает шанс получить балл повыше при проверке.  |
| E11 | Нет возврата из замены к исходной переменной | Запомни: ответ всегда пишется только для исходной переменной. |

## Умножение и деление — 0 баллов

| Код | Ошибка | Совет |
| --- | --- | --- |
| E12 | При умножении или делении на отрицательный множитель не изменён знак неравенства | При умножении или делении на отрицательное число знак меняется. Если множитель содержит переменную, проще перенести всё в одну часть, выделить общий множитель и решить методом интервалов — без деления и разбора знаков множителя по случаям. |
| E13 | При делении на множитель потерян допустимый случай его равенства нулю | Вместо деления перенеси всё в одну часть, выдели общий множитель и решай методом интервалов: так не потеряешь его нули. Например, `(x−2)(x−1)≥x−1; (x−2)(x−1)−(x−1)≥0; (x−3)(x−1)≥0`. |

## Метод интервалов — 0 баллов

| Код | Ошибка | Совет |
| --- | --- | --- |
| E14 | Неверно учтена кратность нуля. Например, ошибка, если знак `(x−1)²` меняется при переходе через 1 | Подпиши кратность корня на оси: через корень чётной кратности знак не меняется, нечётной — меняется. |

## Логарифмы и степени — 0 баллов

| Код | Ошибка | Совет |
| --- | --- | --- |
| E16 | При сравнении логарифмов или степеней с основанием `0<a<1` не изменён знак неравенства | Запомни: при `0<a<1` логарифмическая и показательная функции убывают, поэтому при переходе к сравнению аргументов или показателей знак неравенства меняется. |
| E17 | При сравнении логарифмов или степеней с основанием `a>1` знак неравенства изменён | Запомни: при `a>1` логарифмическая и показательная функции возрастают, поэтому при переходе к сравнению аргументов или показателей знак неравенства сохраняется. |
| E18 | Для переменного основания пропущен возможный случай `0<a<1` или `a>1` | Запомни: при `0<a<1` функция убывает, при `a>1` возрастает. Для переменного основания нужно учесть обе возможные области. |
| E19 | При сравнении степеней потерян допустимый случай основания `a=1` | Запомни: `1^u=1` при любом действительном u. При основании 1 сравниваются две единицы, а не показатели. |
| E20 | Логарифм произведения разложен в сумму логарифмов неположительных множителей | Запомни: `log_a(uv)=log_a(u)+log_a(v)` только при `u>0` и `v>0`. Положительности одного произведения недостаточно. |
| E21 | В `log_a(u²)=2log_a(abs(u))` отброшен модуль при допустимых отрицательных `u` | Запомни: `log_a(u²)=2log_a(abs(u))` при `u≠0`. Модуль нужен, потому что u может быть отрицательным. |

## Чётная степень и модуль — 0 баллов

| Код | Ошибка | Совет |
| --- | --- | --- |
| E22 | Возведение в чётную степень добавило посторонние решения; отбор не выполнен | После возведения в чётную степень явно отбирай полученное множество по исходному условию; отмечай, какой случай исключён и почему. |
| E23 | При возведении в чётную степень потеряны допустимые решения | Запомни: на неотрицательных числах возведение в чётную степень сохраняет порядок, на неположительных — обращает; при разных знаках сравниваются модули. Без учёта знаков такое преобразование может потерять решения. |
| E24 | Модуль раскрыт с неверным знаком. Например, `abs(u)=u` при `u<0` | Запомни: `abs(u)=u` при `u≥0` и `abs(u)=−u` при `u<0`. |
| E25 | Использовано `sqrt(u²)=u` при допустимых отрицательных `u` | Запомни: `sqrt(u²)=abs(u)`, потому что арифметический квадратный корень неотрицателен. |

## Рационализация — 0 баллов

| Код | Ошибка | Совет |
| --- | --- | --- |
| E30 | Замена не сохраняет знак на ОДЗ. Например, `log_(1/2)(x)≥0` заменено на `x−1≥0` вместо `x−1≤0` | *Для модели: на множителе ученика покажи условие совпадения знаков и исправь рационализацию с учётом основания.* |
| E31 | Замена не сохраняет нули. Например, нуль `log₂(x)` при `x=1` заменён нулём `x−2` при `x=2` | Перед рационализацией сверь, при каких значениях на ОДЗ исходный и заменяющий множители равны нулю. |
| E32 | По совпадению знаков заменены отдельные слагаемые; получено неравносильное неравенство | Сначала приведи неравенство к сравнению с нулём и разложи выражение на множители. По знаку заменяй множители, а не отдельные слагаемые. |
| E33 | Совпадение знаков принято за равенство выражений. Например, записано `log₂(x)=x−1` | Записывай переход между неравенствами, а не равенство выражений: совпадение знаков не означает совпадения значений. |
| E34 | Замена по знаку применена при сравнении с ненулевой величиной. Например, `log₂(x)≥2` заменено на `x−1≥2` | Перед рационализацией перенеси всё в одну сторону: сравнение должно быть с нулём. |

## Ошибки на 1 балл

| Код | Ошибка | Совет |
| --- | --- | --- |
| E35 | Только строгость на допустимых граничных точках, включая изолированные нули | Перед ответом подставь допустимые граничные точки в неравенство и сверь круглые и квадратные скобки; отдельно проверь изолированные нули.  |
| E36 | Одна вычислительная ошибка при остальных верных и завершённых шагах, в том числе с ложным «⇔». Исключение — вычисление ОДЗ (E02). Например, `2x≥16 ⇔ x≥4` — 1. | *Для модели: покажи верное действие на ошибочно вычисленном числе ученика и один короткий способ проверки результата.* |
| E37 | Только при переносе в окончательный ответ искажено верно полученное множество; всё решение до этого, включая отбор по ОДЗ, выполнено верно. Например, для `(x−1)/(x−2)≥0` правильно получено `(-∞;1]∪(2;+∞)`, но в ответ перенесено `(-∞;−1]∪(2;+∞)` или `(-∞;1]∪[2;+∞)` — 1 в обоих случаях.  | Внимательность нарабатывается практикой. Запоминай, что чаще теряешь при переписывании — минусы, скобки или промежутки, — и перепроверяй именно эти места. Главное — ботай! |

## Не ошибка — при остальном верном решении 2 балла

| Ситуация |
| --- |
| Не в большей части решения опущены отдельные переходы или простые рассуждения, выполнимые в уме; по записанному решению в целом логика ясно прослеживается. |
| Ограничения учтены без отдельного заголовка «ОДЗ» |
| При вычислении верной ОДЗ не повторено избыточное условие |
| Диапазон замены учтён при возврате, но не выписан отдельно |
| Готовая правильная факторизация записана без деления многочлена |
| При обычном корректном методе интервалов не расписан расчёт каждого знака |
| Достаточное обоснование дано формулами или осью без словесного пересказа |
| Использован другой корректный метод или эквивалентная форма ответа |
