# Критерии проверки и оценка решений задания 19

Задание № 19 — это уравнение, неравенство или их система с параметром. Требуется найти все значения параметра (обычно `a`), при каждом из которых выполнено условие: ровно два / три / четыре решения, хотя бы одно решение, единственное решение и т. п.

Задачи с параметром допускают разные способы решения: чисто алгебраический; геометрический (построение и исследование модели на плоскости `Oxy` или `Oxa`); функциональный (исследование функции, часто после замены). В одном решении могут сочетаться элементы всех трёх способов.

Возможны различные способы и записи развёрнутого решения. Главное требование — решение должно быть математически грамотным, из него должен быть понятен ход рассуждений автора работы. В остальном (метод, форма записи) решение может быть произвольным. Полнота и обоснованность рассуждений оцениваются независимо от выбранного метода решения. При этом оценивается продвижение выпускника в решении задачи, а не степень следования «эталонному» решению.

При решении задачи можно использовать без доказательств и ссылок математические факты, содержащиеся в учебниках, допущенных к использованию при реализации имеющих государственную аккредитацию образовательных программ среднего общего образования.

## Общая схема

В ФИПИ у каждой задачи своя таблица критериев с конкретными точками и конкретной моделью. Ниже — общая схема, выведенная из всех таблиц 2026 года (демоверсия и задачи 18.1–18.6 методических рекомендаций). Если вместе с задачей передана её собственная таблица критериев, она имеет приоритет.

| Критерии оценивания выполнения задания | Баллы |
| :--- | :---: |
| Обоснованно получен верный ответ | 4 |
| С помощью верного рассуждения получено множество значений `a`, отличающееся от искомого только включением и/или исключением **граничных точек** — концов промежутков ответа | 3 |
| С помощью верного рассуждения получена **основная часть** ответа: промежуток (промежутки) ответа, возможно с ошибкой в граничных точках, но с потерянным изолированным значением `a` и/или с невыколотыми внутренними особыми точками, ИЛИ при всех значениях `a` верно и полностью исследован один из двух случаев (раскрытие модуля, одна из ветвей совокупности), ИЛИ получен неверный ответ из-за вычислительной ошибки, но при этом верно выполнены все шаги решения | 2 |
| Задача **верно сведена** к исследованию: расположения корней квадратного уравнения относительно числа (после замены с верно найденной областью значений), взаимного расположения линий (параболы, окружности, их дуг, прямых, лучей) аналитически или графически, найденных корней при записанных условиях | 1 |
| Решение не соответствует ни одному из критериев, перечисленных выше | 0 |
| *Максимальный балл* | 4 |

Каждая строка, кроме 0 и 1, требует **верного рассуждения**. Совпадение формы ответа с описанием строки само по себе балл не даёт: ответ `[−2; 2]`, полученный неверной логикой, не даёт 2 балла за «промежуток `(−2; 2)` с граничными точками» (пример 18.4.4 — 1 балл).

## Как применить схему к конкретной задаче

Перед оценкой разметь эталонный ответ и эталонное решение.

1. **Критические значения.** Выпиши все значения `a`, при которых меняется число решений: касание (`D = 0`), прохождение линии через конец дуги или луча, через общую точку двух кусков, совпадение корней, попадание корня на границу области замены или в нуль знаменателя (`f(t₀) = 0`).
2. **Роль каждого критического значения в ответе:**
   - **граничная точка** — конец промежутка ответа, включённый (`≤`) или невключённый (`<`). Ошибка только в ней — 3 балла. Пример: в ответе `−9 ≤ a < 3` граничные точки `−9` и `3`;
   - **изолированное значение** — отдельная точка ответа вне промежутков (обычно касание): `a = −13` в ответе `a = −13; −9 ≤ a < 3`. Его потеря — не больше 2 баллов;
   - **выколотая внутренняя точка** — значение внутри промежутка, исключённое из ответа: `−4` в ответе `(−5; −4) ∪ (−4; −3)`, `±1` в ответе `[−2; −1) ∪ (−1; 1) ∪ (1; 2]`. Если она не выколота, это не больше 2 баллов;
   - **лишняя точка, где решений нужного количества нет**, вне промежутков ответа — обычно не граничная; см. «Спорные случаи».
3. **Основная часть ответа** — объединение промежутков ответа без изолированных значений и без выколотых точек: `(−9; 3)`, `(−5; −3)`, `(−2; 2)`, `(−1−√13; −1+√13)`.
4. **Сведение** — место эталонного решения, после которого остаётся стандартное исследование. Определи его по эталону, а у ученика проверь, что модель **верная полностью**:
   - замена `t = g(x)`: найдено множество значений `t` и сколько `x` соответствует каждому `t` (например, при `t > 2` — два `x`, при `t = 2` — бесконечно много, при `t < 2` — ни одного), записано, сколько корней и где должно иметь уравнение относительно `t`;
   - геометрическая модель: каждое уравнение верно описано как множество на плоскости с учётом ограничений (дуга, а не вся окружность или парабола; луч, а не прямая; полуплоскость из условия раскрытия модуля), понятно, какой объект зависит от `a` и как он движется;
   - алгебраическая модель: корни найдены явно, и записаны все условия, которым они должны удовлетворять (ОДЗ, знак правой части, различие корней).

   Картинка или запись модели без начатого исследования, с выводами, противоречащими модели, — не сведение (пример 18.2.4 — 0 баллов). Неверная модель (неверная область значений замены, потерянное ограничение) — 0 баллов даже при частично верном ответе (пример 18.1.4).
5. **Случаи.** Если эталон делит решение на два независимых случая (две ветви модуля, два множителя), полное и верное исследование одного из них при всех `a` — 2 балла.

Если передан только ответ без эталонного решения, критические значения и роль каждой точки определи сам по условию; основную часть и граничные точки — по ответу. Сведение тогда засчитывается за любую верную полную модель, а не за конкретную из таблицы ФИПИ.

## Обоснование

- 4 балла требуют, чтобы были найдены все критические значения и для каждого промежутка между ними и для каждого критического значения было указано (аналитически или по рисунку с пояснением) число решений. Таблица или список вида «при `a < −13` — 1 решение, при `a = −13` — 2, …» — достаточное обоснование (пример 18.3.1).
- Верный ответ, где найдены только критические значения, а число решений на промежутках не исследовано, не обоснован: оценка по самому высокому критерию, элементы которого обоснованы (пример 18.3.2 — верный ответ, 2 балла: «решение не является обоснованным, но получен промежуток»).
- Значение касания или прохождения, записанное без вычисления, но верное и вытекающее из известного факта (касательная перпендикулярна радиусу, наклон прямой, проходящей через две известные точки), не снижает балл, если остальное исследование есть (пример 18.5.1 — 4 балла).
- Неточность записи (например, знак в условии раскрытия модуля), если дальнейшие рассуждения ведутся при верном условии, не снижает балл.

## Порядок выставления

1. Сверь ответ ученика с эталоном поэлементно: основная часть, граничные точки, изолированные значения, выколотые точки.
2. Проверь сведение (п. 4). Нет верного сведения — 0.
3. Найди первый неверный шаг. Если он вычислительный, единственный и все шаги решения есть — не меньше 2.
4. Выбери самую высокую строку, все условия которой выполнены верным рассуждением.

## Спорные случаи

- **Лишнее изолированное значение** при верной основной части (например, в ответ добавлено значение касания, при котором корень не попадает в нужную область) в таблицах 2026 не описано. Не ставь 3; ставь 2, если основная часть получена верным рассуждением, — по аналогии с потерей изолированного значения.
- **Ответ — конечный набор значений** (таблицы прошлых лет): 3 — получены все верные значения, но добавлены одно-два лишних или решение недостаточно обосновано; 2 — верным рассуждением получено хотя бы одно верное значение.
- В 18.6 включение лишних значений, где корень совпадает с нулём знаменателя (внутренние выколотые `−1, 0, 3, 8`), даёт 2, а включение конца промежутка `−2` — 3. Это подтверждает правило: 3 только за концы промежутков.
- Таблица ФИПИ может быть составлена для другого варианта задачи с другими знаками (в методичке 2026 для 18.5 таблица называет точки `−7/4` и `8`, а работы написаны к варианту с ответом `−8 ≤ a ≤ 7/4`). Конкретные точки бери из эталонного ответа той задачи, которую решал ученик.
