# Задачи с параметром: ошибки и оценка

Балл в заголовке раздела — наибольший, который остаётся при этой ошибке, если остальное решение верно. Термины «граничная точка», «изолированное значение», «выколотая внутренняя точка», «основная часть ответа» и «сведение» определены в `criteria.md`: перед выбором кода разметь эталонный ответ по этим ролям.

## Неверная модель — 0 баллов

| Код | Ошибка | Совет |
| --- | --- | --- |
| E01 | Неверно найдено множество значений новой переменной или не учтено, сколько значений исходной переменной соответствует каждому значению новой. Например, для `t = abs(x−a−1) + abs(x−a+1)` взято `t > 0` вместо `t ≥ 2`, или не замечено, что при `t = 2` корней бесконечно много (18.1.4) | Перед заменой исследуй функцию `t(x)`: её наименьшее значение и сколько раз она принимает каждое значение. Запиши итог: «при `t < 2` корней нет, при `t = 2` — бесконечно много, при `t > 2` — два». Только после этого ставь условие на корни уравнения относительно `t`. |
| E02 | При сведении потеряно ограничение исходной задачи: ОДЗ, условие `x − y + 3 ≥ 0` под корнем, знаменатель не равен нулю, неотрицательность правой части в `sqrt(f) = g` или `abs(f) = g` | Выписывай ограничения рядом с исходным уравнением до любых преобразований и переноси их в каждую систему. Каждую найденную точку пересечения проверяй по этим ограничениям. |
| E03 | Обе части возведены в квадрат без условия неотрицательности; посторонние корни не отобраны. Например, `abs(3x) = 2x + 2 + a` заменено на `9x² = (2x + 2 + a)²` без условия `2x + 2 + a ≥ 0` (18.6.2) | Запомни: `abs(f) = g` равносильно системе `g ≥ 0`, `f = g` или `f = −g`; `sqrt(f) = g` — системе `g ≥ 0`, `f = g²`. В задачах с параметром удобнее раскрыть модуль по промежуткам `x` и получить кусочно-линейную функцию. |
| E04 | Неверно построено или описано множество на плоскости: вся парабола или окружность вместо дуги, прямая вместо луча, перепутана полуплоскость из условия раскрытия модуля, неверны центр, радиус, вершина или направление ветвей | После раскрытия модуля каждую линию бери только в своей полуплоскости и отмечай концы дуг и лучей. Проверяй построение по двум-трём точкам, подставляя их в исходное уравнение. |
| E05 | Перепутаны система и совокупность: условия, которые должны выполняться одновременно, объединены, или альтернативные случаи пересечены. *Для модели: знак скобки в расшифровке ненадёжен. Ставь E05, только если путаница видна по дальнейшей работе с условиями и меняет множество.* | Запомни: система означает «и», совокупность — «или». Разбор модуля и разложение на множители дают совокупность, а ограничения ОДЗ присоединяются системой к каждой ветви. |
| E06 | Решена другая задача: другое уравнение из-за ошибки при переписывании условия, или вместо «ровно `n` решений» искалось «есть решения», или не учтено слово «различных» | Перед решением сверь записанное условие с заданием: числа, знаки, модули, требуемое количество решений. |
| E07 | Есть только рисунок или запись модели, исследование расположения не начато; выводы о числе решений противоречат рисунку (18.2.4) | Рисунок — не решение. Для каждого положения подвижной линии найди значение `a` (касание, прохождение через конец дуги) и подпиши число общих точек. |
| E08 | Пропущено существенное рассуждение, без которого модель вынуждена сама восстанавливать модель или этап решения | *Для модели: укажи конкретный непонятный переход и предложи короткую промежуточную запись, которая делает ход решения прослеживаемым.* |

## Неверное исследование при верном сведении — 1 балл

Если сведения нет, эти ошибки ведут к 0.

| Код | Ошибка | Совет |
| --- | --- | --- |
| E09 | Подсчёт решений без учёта ограничений модели: «`D > 0` — два решения» без проверки, что оба корня попадают в нужную область (`t > 2`, отрезок `[0; 6]`, дуга) | Количество корней квадратного уравнения — ещё не количество решений исходной задачи. Для каждого корня проверь, лежит ли он в нужной области и сколько решений исходной задачи ему соответствует. |
| E10 | Условие для найденных корней заменено условием «при всех `x`» или наоборот. Например, `x² + ax + 1 ≥ 0` в корнях `x = 1 − a`, `x = −1 − a` заменено требованием `D ≤ 0` (18.4.4) | Подставь каждый найденный корень в условие и получи неравенство относительно `a`. Нужно, чтобы условие выполнялось в корнях, а не на всей прямой. |
| E11 | Неравенства с корнем от выражения с параметром решены возведением в квадрат без условий на знаки обеих частей (18.1.3) | Условия расположения корней квадратного трёхчлена относительно числа `t₀` удобнее записывать без формулы корней: `f(t₀) < 0` — число между корнями; для обоих корней по одну сторону — знак `f(t₀)`, `D` и положение вершины. Если всё же сравниваешь корень с числом, разбери знаки обеих частей перед возведением в квадрат. |
| E12 | Неверно записаны условия расположения корней квадратного трёхчлена: пропущено условие на `D`, вершину или знак старшего коэффициента; не разобраны случаи, когда коэффициент при старшей степени зависит от `a` и может быть равен нулю | Нарисуй эскиз параболы для каждого нужного расположения и выпиши условия по нему: знак старшего коэффициента, `D`, значение в точке `t₀`, положение вершины. Отдельно разбери значение `a`, при котором уравнение перестаёт быть квадратным. |
| E13 | Найдены только критические значения `a`; число решений между ними не исследовано, в ответ выписаны сами критические значения (18.3.3) | Критические значения разбивают ось `a` на промежутки. Для каждого промежутка и каждого критического значения запиши число решений, затем выбери нужные. |
| E14 | Значение касания или прохождения через точку найдено «по рисунку» и неверно; аналитического подтверждения нет | Рисунок подсказывает, какие положения важны, но значение `a` находи вычислением: условие касания через `D = 0` или через перпендикуляр к радиусу, прохождение — подстановкой координат точки. |
| E15 | Разобран только один из необходимых случаев (ветвь модуля, множитель совокупности), и он исследован не полностью | *Для модели: выпиши пропущенный случай рядом с разобранным и покажи, как коротко обозначить все случаи перед исследованием.* |
| E16 | Две или более независимые вычислительные ошибки | Обидные ошибки при счёте уходят с практикой. Запоминай, где чаще всего ошибаешься, и перепроверяй эти места подстановкой. Главное — ботай! |

## Ошибки на 2 балла

| Код | Ошибка | Совет |
| --- | --- | --- |
| E17 | Потеряно изолированное значение параметра при верной основной части ответа: обычно касание (`D = 0`), когда единственный корень попадает в нужную область. Например, потеряно `a = −13` в ответе `a = −13; −9 ≤ a < 3` | Отдельно разбирай случай `D = 0`: проверь, где лежит единственный корень и сколько решений исходной задачи он даёт. Такие значения часто стоят в ответе отдельной точкой. |
| E18 | Не выколота внутренняя особая точка: совпадение корней, попадание корня в нуль знаменателя или в общую точку двух кусков модели. Например, получено `(−5; −3)` вместо `(−5; −4) ∪ (−4; −3)` (18.2.3) или `(−2; 2)` вместо `[−2; −1) ∪ (−1; 1) ∪ (1; 2]` | Когда требуется «ровно `n` различных» решений, проверь, при каких `a` найденные корни совпадают друг с другом или попадают в запрещённые точки. Найденные значения выколи из ответа. |
| E19 | В ответ включено лишнее значение, при котором нужного числа решений нет, и оно не является концом промежутка ответа (лишняя внутренняя или отдельная точка) | Подставь каждое отдельное значение `a` из ответа в условие и пересчитай решения: изолированные точки ответа проверяй всегда. |
| E20 | Одна вычислительная ошибка при верных и завершённых шагах решения, ответ из-за неё неверный. Например, `(−a−1)² + a(−a−1) + 1 ≥ 0` упрощено до `a ≥ −1` вместо `a ≥ −2` (18.4.3) | *Для модели: покажи верное действие на ошибочно вычисленном выражении ученика и один короткий способ проверки результата — например, подстановку конкретного `a`.* |
| E21 | Верный ответ (или верная основная часть) без обоснования: найдены критические значения, но число решений на промежутках не исследовано (18.3.2) | Обоснование ответа — это число решений на каждом промежутке и в каждой критической точке. Запиши его списком: «при `a < −13` — одно решение, при `a = −13` — два, …». |
| E22 | Полностью и верно исследован только один из двух независимых случаев (одна ветвь модуля, один множитель), второй не разобран или разобран неверно | *Для модели: покажи, как результат второго случая объединяется с первым; если случаи дают общие точки, покажи, как их не посчитать дважды.* |

## Ошибки на 3 балла

| Код | Ошибка | Совет |
| --- | --- | --- |
| E23 | Неверна строгость в условии, определяющем конец промежутка: `> 0` вместо `≥ 0`, `<` вместо `≤`. Ответ отличается только граничными точками (18.4.2) | Подставь каждую граничную точку в исходную задачу и посчитай решения: так сразу видно, включать её или нет. |
| E24 | Неверно посчитано число решений в граничном положении: при касании или прохождении через конец дуги, луча, общую точку двух кусков. Ответ отличается только концами промежутков (18.5.2: касание в общей точке дуг посчитано как три решения) | В граничном положении отметь на рисунке все общие точки и проверь, не совпадает ли точка касания с уже посчитанной точкой. Совпадающие точки — одно решение. |
| E25 | Верно полученное в решении множество искажено только в концах промежутков при переносе в ответ | Перед записью ответа сверь каждую скобку с выводом в решении: круглая — конец не входит, квадратная — входит. |

## Не ошибка — при остальном верном решении 4 балла

| Ситуация |
| --- |
| Использован другой корректный метод: графический в `Oxy` или `Oxa`, функциональный, аналитический, их сочетание; эталонный ход не обязателен |
| Значение касания или прохождения записано без вычисления, но оно верное и следует из известного факта (касательная перпендикулярна радиусу; прямая через две известные точки), а число решений на промежутках исследовано (18.5.1) |
| Неточность записи, после которой рассуждения ведутся при верном условии (например, знак в условии раскрытия модуля) |
| Рисунок — эскиз не в масштабе, если ключевые точки и положения подписаны, а критические значения найдены аналитически |
| Число решений на промежутках записано таблицей, списком или подписями на рисунке без словесного пересказа |
| Ответ записан в другой эквивалентной форме: промежутками, двойными неравенствами, объединением, `8/√3` вместо `8√3/3` |
| Ошибки в черновых вычислениях сбоку или в зачёркнутом, если в решение перенесено верное значение |
| Избыточно подробное решение, лишние верные проверки |
