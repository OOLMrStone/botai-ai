## Как делали

По постановке руководителя («запусти ресерч в несколько агентов по файлу ФИПИ, разбору проверок Школково и других онлайн-школ, каналу Алипаши и выдели типичные ошибки») и пользователя («агенты должны спорить: один предлагает, другой критикует»):

1. Три исследователя параллельно: материалы ФИПИ (методички для экспертов 2022–2026, МР для учителей 2021–2026, демоверсия 2026); канал [egenaprogib](https://t.me/egenaprogib) (Алипаша Бабаев, 2865 постов); онлайн-школы и эксперты («Школа экспертов» Решу ЕГЭ, региональные комиссии, Telegram-каналы школ).
2. Их находки сведены в 27 предложений правок (P1–P27).
3. Критик проверил каждое по первоисточникам. Правило спора: **ФИПИ всегда важнее**; если ФИПИ молчит, не-ФИПИ источник — повод для вопроса пользователю, а не основание правила.
4. Возражения критика вернулись исследователям; они защищали или уступали. Несогласованное — вопросы пользователю.

Нумерация: проект 14/15/18 = ФИПИ-2024…2026 №13/14/17 = ФИПИ-2022…2023 №12/13/16.

## Главные находки

- **Указания по оцениванию, ФИПИ-2022, с. 115–117** (в 2023–2026 не повторены): ошибка в промежуточной выкладке — не максимальный балл; факт не из учебника без доказательства — решение недостаточно обосновано; решена задача с другими данными — 0; неточный рисунок при верной конфигурации балл не снижает.
- **Неточность записи при верных значениях максимум не снижает** — ФИПИ-2025, пример 18.1.1, с. 168 (4 из 4, «неточность в записи» при раскрытии модуля).
- **Граница «вычислительная / не вычислительная» в №13 у ФИПИ:** неверное действие над числами — вычислительная (13.6.1: деление 8/4); неверная формула — нет (13.6.2: знаменатель 2 вместо 2a; потерян минус в формуле приведения).
- **«Арифметическая» в №14/№17 у ФИПИ:** `√(8 + 25) = 4√2` — арифметическая (17.2.3, 2 балла); `√(1/18) = 1/3`, вынесение множителя из-под корня, плюс вместо минуса в теореме косинусов, не тот угол, длина вектора нормали — не арифметические.
- Одна буква параметра для нескольких серий допустима — МР-2021, с. 22.
- Только ответ в пункте б без отбора недопустим — МР-2022 с. 12 («0 баллов за второй пункт»), МР-2025/2026 с. 15.
- Слайд Тюменского семинара «ЕГЭ 2023» искажает пример ФИПИ 12.4.2 («из-за» вместо «не из-за» вычислительной ошибки) — тезис «только одна вычислительная ошибка» опоры в ФИПИ не имеет.
- Школы местами противоречат ФИПИ (100балльный: 0 за незакрашенную дугу при решённом а; ЕГКР: 0 за неподписанные оси) — не учитывать.
