## Задание 14 (уравнение)

- **P1. «Не ошибка»: серия без `n ∈ Z`, если по записи ясно, что параметр целый.** За: Решу ЕГЭ №513091 — 2 балла (Р, не ФИПИ); демоверсия 2026 с.19 «Эксперты проверяют только математическое содержание… особенности записи не учитывают» (Ф, общее); региональный пересказ конференции «Профиматика» 2026: «снижения не предусматривается, но не приветствуется» (Рег). Против: прямой позиции ФИПИ нет; все 8 работ ФИПИ на 2 балла содержат `n ∈ Z`.
- **P2. Строка «Один параметр для всех серий…» — источник теперь Ф** (МР-2021 с.22 «можно использовать одну букву»). Текст не меняется.
- **P3. E14: не добавлять «одна».** Критерий ФИПИ: «из-за вычислительной ошибки» (ед. ч.); все примеры ветки — одна ошибка; пользователь: «ФИПИ всегда важнее» → формулировка ФИПИ без собственного правила. Против: Тюменский семинар (Рег, со ссылкой на ФИПИ-2023) — «на 1 балл может быть допущена только одна вычислительная ошибка»; видео uchus.online «две вычислительные ошибки» (не проверено).
- **P4. E10 (перебор остановлен на корне отрезка): исключение — конец отрезка сам является корнем.** Краснодар (Рег, 2025): если конец отрезка — корень, выход на границу считается показанным; для серии без корней на отрезке нужен выход за обе границы. Сейчас совет E10 требует выйти «за оба конца отрезка» — риск ложного E10.
- **P5. E04: добавить «неверно использована чётность/нечётность функции»** — МР-2025 с.17 (Ф) называет типичной; баллы не указаны (по критерию — пункт а не обоснован).
- **P6. Граница E04/E14: неверно вычисленная степень (`8^(1/2) = 4`) или неверное сравнение чисел — не вычислительная ошибка.** egenaprogib 2339, 2346 (Р + ссылка на критерии, не ФИПИ-документ); «принцип наихудшего прочтения»: если ошибку можно объяснить не арифметикой — не арифметика (1576, 1725, 2488, 3571 — Ш); Тюмень (Рег): вычислительная — только +, −, ×, ÷. ФИПИ прямого определения не даёт.
- **P7. E12 (корни б без отбора): источник Ф** — МР-2026 с.15 «Недопустимо в пункте «б» приводить только ответ»; МР-2022 с.12 «очевидно из рисунка» → 0 за б. Возможно, добавить в E12 пример «ответ б без отбора со ссылкой „видно по рисунку“».
- **P8. Конфликт со строкой «Не ошибка: неточность в записи промежуточного вычисления…».** Указания ФИПИ 2022 с.116 (Ф): ошибка в промежуточной выкладке, даже не повлиявшая на ответ, — не максимальный балл. Но ФИПИ 2024 13.3.2 / 2025 13.4.2: «неточность в записи дискриминанта — объединение записей D и √D» — пункт а засчитан. Решу ЕГЭ №515919 (Р): явная описка в а, не повлиявшая на ответ, — 2. Предложение: оставить строку, но сузить до «неточность ЗАПИСИ (не ошибка в вычислении)»; ошибку в промежуточной выкладке отнести к E14 (не максимальный балл).
- **P9. «Не ошибка»: переход к `tg x` без оговорки `cos x ≠ 0`, если `cos x = 0` не даёт корней.** Рег/Ш (toipkro; egenaprogib 2327 — А). Не ФИПИ.
- **P10. «Не ошибка»: ответ через невычисленный `arcsin`, `arccos` табличного значения.** Рег/Ш (toipkro; egenaprogib 1494 — А). Не ФИПИ.
- **P11. Отбор без окружности (логарифмы, корни): сравнение чисел разной природы нужно показать; проверка только одной границы — отбор не обоснован.** egenaprogib 2327, 2341, 2342 (Р, 1 балл). Не ФИПИ-документ. Куда: расширить E12 или E11.
- **P12. «Не ошибка» для окружности: оси не подписаны; точка стоит в нужной четверти без точного положения; расчёт угла не показан.** egenaprogib 1517, 3323, 2446 (А). Против: 100балльный/ЕГКР ставят 0 за подписи осей — противоречит ФИПИ (в требованиях ФИПИ этого нет).
