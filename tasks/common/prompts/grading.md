# Подведение итогов

## Цель

Прочитай `response-format.md`, заверши проверку и верни один JSON-объект по этому формату — это весь итоговый ответ. Ответ не содержит ничего, кроме JSON. Все объяснения и советы находятся внутри предусмотренных полей JSON; снаружи нет ни текста, ни Markdown-обрамления.

## Оценка

На основе `notes.md` и всей проверки в этой сессии оцени работу целиком по `criteria.md` с учётом точных правил `popular_mistakes.md`. Индивидуальные критерии задачи имеют приоритет. Выставь один итоговый балл и объясни его; советы по ошибкам составь из `notes.md` и справочника.

Анализ завершён: используй окончательную рецензию `notes.md`, не меняй её и не возвращайся к фотографиям. На этой стадии выставь балл и сформируй ответ по результатам анализа. Для рецензии во фронт убери из текста только пометки E-кодов вида `[E08]` и один пробел перед каждой такой пометкой, если он есть; остальной текст сохрани дословно. Сам `notes.md` не меняй. E-коды используй для оценивания и служебного поля `analysis.errors[].code`, не включай их в пояснения ученику.

## Проверка ответа

Сохрани полный текст будущего ответа через `write_file` в `response.json` и запусти Python-валидатор инструментом `validate_response({"path":"response.json"})`. Он проверяет весь ответ: единственный JSON-объект без содержимого снаружи и точное соответствие структуре `response-format.md`.

Пока проверка не пройдёт, исправляй ответ и запускай её заново. После успеха верни проверенный текст без изменений и дополнений.
