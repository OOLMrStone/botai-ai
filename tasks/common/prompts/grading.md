# Подведение итогов

## Цель

Прочитай `response-format.md`, заверши проверку и верни один JSON-объект по этому формату — это весь итоговый ответ. Ответ не содержит ничего, кроме JSON. Все объяснения и советы находятся внутри предусмотренных полей JSON; снаружи нет ни текста, ни Markdown-обрамления.

## Оценка

На основе `Notes.md` и всей проверки в этой сессии оцени работу целиком по `criteria.md` с учётом точных правил `popular_mistakes.md`. Индивидуальные критерии задачи имеют приоритет. Выставь один итоговый балл и объясни его; советы по ошибкам составь из Notes и справочника.

Если что-то спорно или непонятно, вернись к соответствующему месту на исходных фотографиях, разреши сомнение и уточни связанный вывод в Notes и окончательную оценку.

Если существенный фрагмент исходных фотографий остаётся объективно нечитаемым, подготовь ответ с `is_graded=false` и краткой причиной по `response-format.md`, без балла. Сохрани и проверь этот JSON так же, как обычный ответ.

## Проверка ответа

Сохрани полный текст будущего ответа через `write_file` в `response.json` и запусти Python-валидатор инструментом `validate_response({"path":"response.json"})`. Он проверяет весь ответ: единственный JSON-объект без содержимого снаружи и точное соответствие структуре `response-format.md`.

Пока проверка не пройдёт, исправляй ответ и запускай её заново. После успеха верни проверенный текст без изменений и дополнений.
